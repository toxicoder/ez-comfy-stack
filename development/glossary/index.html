Models

Klein 4B

Apache still-image model. Distilled FP8, 4 steps, CFG 1.0. Default T2I engine.

Wan 2.2

Apache silent motion model (T2V + I2V). No native audio. Daily-driver 5 s clips.

LTX-2.5

Joint audio/video model (Community License, gated, $10M company-revenue cap).

Qwen3-4B

Klein's text encoder (CLIP type flux2) and the Prompt Enhance GGUF family.

UMT5-XXL

Wan 2.2 text encoder (CLIP type wan).

Gemma 4

LTX-2.5 text encoder: Gemma4-12B-with-proj, CLIP type ltxv.

ACE-Step

MIT local music / bed engine. Opt-in ~10 GB AIO; do not co-resident with LTX.

Kokoro

Apache ONNX/CPU TTS with built-in voices. Default podcast speech engine.

Chatterbox

Optional MIT GPU TTS. PerTh watermark stays on. Not a download-models default.

Chatterbox Multilingual

MIT 23-language zero-shot clone. PerTh watermark stays on. Opt-in download-dub --tier clone.

CLIP

Text encoder that turns a prompt into conditioning for the sampler.

VAE

Encoder/decoder between pixels and latent space. Each model family has its own.

UNET

Denoiser / transformer weights that turn noise + conditioning into a sample.

GGUF

llama.cpp weight format. Prompt Enhance uses a ~2.5 GiB Qwen3-4B Q4_K_M file.

MagCache

Optional Wan draft accelerator. On wan-i2v-5s only; never on LTX heroes.

Nunchaku

Optional quantized engine. Lab graphs do not require it; PyPI nunchaku is the wrong package.

SeedVR2

Optional Apache restorer for a still PNG or a stitched 90s master. Not part of download-models.

TRELLIS.2

Optional MIT 3D pack on MODELS_DIR. No nvdiffrast. Host occupancy with Comfy.

DA3-BASE

Optional Apache depth model. DA3-LARGE is refused.

LongCat-Video

Optional MIT video pack. No NCCL. Not a 90s default.

DreamX-Creator

Optional Apache joint-AV pack. DreamX-World is refused.

Fun InP

Optional Wan first-last-frame pack (~47 GB Apache). MagCache off.

VACE

Optional Wan 2.1 1.3B 17-frame join (1+8n). MagCache off. Unload LTX first.

Z-Image Turbo

Optional Apache still runner-up. Not the default Klein path.

VideoHelperSuite

Comfy pack that writes MP4 (and GIF). Open the Save video node after Queue for preview.

Qwen3-TTS

Optional Apache TTS + voice design. Not the Kokoro default.

FP8

8-bit float weight format used by default Klein distilled and some Wan packs.

INT8-convrot

Quantized LTX-2.5 transformer format used by the lab distilled weights.

NVFP4

Optional Klein 4B still UNET quant. Apache. Not the distilled FP8 default.

IC-LoRA

Opt-in LTX Union Control LoRA (~1 GB). Not in download-models or LTX --tier all.

DualCLIP

LTX-2.3 text-encoder pair. Lab 2.5 graphs use CLIPLoader Gemma4, not this.

Gemma 3

LTX-2.3 DualCLIP text encoder (~8–9.5 GB). Auto-pulled with 2.3/balanced/quality.

Wan A14B

Optional Wan 2.2 I2V 14B FP8 pack (~20 GB). Unload 5B first. Not download-models.

DINOv3

Vision companion pulled with TRELLIS.2. Not a standalone Queue model.

nvdiffrast

Banned 3D pip extra. TRELLIS.2 on this stack never needs it.

Qwen3.6-35B

Opt-in ~23 GB UD-Q4_K_XL GGUF for occupancy llm-desk. Not download-models.

Modalities

T2I

Text-to-image: a prompt becomes a still (PNG). Klein's job.

I2V

Image-to-video: a start still plus motion text becomes a clip. Start image owns look.

T2V

Text-to-video: no start image. Wan T2V is silent; LTX T2V is joint AV.

A2V

Audio-to-video: picture follows a soundtrack (audio freeze, not lip-sync OSS).

S2V

Speech-to-video (optional Wan 2.2 S2V 14B). Not a download-models default.

joint AV

Audio and video in one transformer pass. LTX-2.5's job; Wan cannot do this.

first-last-frame

Condition a clip on both a first and last still (Wan Fun InP).

ping-pong

Play a clip forward then reverse so the join frame equals the start (GIF/bumper loops).

Studio

Asset Bible

Versioned 3D asset catalog under COMFY_OUTPUT_DIR/assets. Outputs, never MODELS_DIR.

ComfyUI

Node-graph UI for local image, video, and audio generation. This stack's studio.

Nodes 2.0

ComfyUI's Vue-based node renderer. Default canvas on this studio.

workflow

A saved ComfyUI graph (JSON). Lab examples are already wired — change widgets, not the file.

Queue

One run of the current graph: encode, sample, decode, save.

widget

A control on a Comfy node (prompt, seed, width, filename, Enhance toggle).

App Mode

ComfyUI widget surface on a saved graph (frontend 1.41.13+). Same JSON as graph view.

Quality widget

App-global Lab / Draft / High / Free Commercial Use combo. Family-specific overlays. Not --tier quality.

lab_app_mode

Lab extra on shipped graphs: lane, occupancy, handoff, frontend_min.

latent

Compressed representation the sampler denoises. Frame count × size live here, not in the PNG yet.

KSampler

Node that denoises latents for N steps at a CFG, seed, and scheduler.

CFG

Classifier-free guidance scale. Distilled Klein wants 1.0 — do not 'turn it up for quality'.

seed

RNG lock for a Queue. Same seed + same graph ≈ same picture; change it to explore.

Prompt Enhance

In-tree nodes that rewrite a lazy sentence into model-native CLIP text via a CPU GGUF.

world bible

Locked description of a place or character with no camera. Shared across shots.

identity still

Klein frame that locks wardrobe/place so later I2V shots stay the same person or house.

lab-example

A seeded `_lab/<lane>/` graph. Load these; do not start from a blank canvas.

Note node

On-canvas operator note: purpose, models, sampler, prompting tips, run steps.

LoadImage

Node that feeds a PNG into I2V. Point it at your still, not only example.png.

Enhance

Toggle on Prompt Enhance. Off pins your widget text; on rewrites it for CLIP.

Research Chat

Inspire App: CPU chat + web search + sequential research subagents. Occupancy llm.

research-mcp

In-tree MCP for chat, web search, research, and lab-app discovery. No execute_code.

App Forge

No-UNET Inspire App that clones a shipped lab graph into live _user/ as a new App.

studio-mcp

In-tree MCP that clones lab graphs into live _user/. No execute_code. No Queue.

Guide pack

DCC handshake: 1280×704 clay/depth/canny/first+last for a 5.00s print.

house-views

Blender greybox + ten 1024×1280 Instagram clay stills. Occupancy XOR.

blender-stills

Single-frame clay/depth/canny dump at creator sizes. Occupancy: blender-desk.

ezcmd

Interactive docs fence: body `id: <recipe>` matching includes/command-builder.json.

Occupancy gate

In-canvas node that reads occupancy JSON only. Does not start Compose or spawn Blender.

promote-workflow

manage.sh copies a keeper graph into workflows/_lab/<lane>/. Does not commit.

studio-ui

Optional Compose profile jobstore board on :8190. Not App Mode.

clay

Greybox / Workbench pass (still or 5 s video) that Klein or LTX restyles.

Canny

Edge / outline pass from Blender or a still. Control for Klein or IC-LoRA.

LoRA

Small adapter on a base UNET. Lab default graphs do not require one.

ControlNet

Structure guide (Canny/depth). Lab film uses IC-LoRA Union, not a second SD1.5 net.

Prompt Join

Node that locks a shot card onto a world bible (lock=view or lock=state).

CLIP prompt

Dim box on Prompt Enhance: the string CLIP actually encoded after Queue.

Prompt Forge

Inspire App that turns a research brief or lazy sentence into Klein/Wan/LTX prompts.

Cinema Rack

Inspire App that splices cinematography dropdowns into Klein, Wan, and LTX prompts.

technique splice

Composing one cinematography clause per axis into a single CLIP prompt.

Beat Sheet

Inspire App: logline / script / audio policy / score packed into shot cards.

SaveImage

Writes a PNG under COMFY_OUTPUT_DIR. Last-frame savers feed the next I2V start.

SaveAudio

Writes FLAC/MP3 from ACE-Step, podcast, or dub graphs. Not a YouTube MP4.

Comfy Manager

Node installer inside Comfy. Lab graphs must not depend on a Manager click.

Sage Attention

Alternate attention backend. Never pass it next to Comfy Kitchen on this stack.

VAE grid

LTX spatial size must be divisible by 32. Lab landscape is 1280×704, not 720.

1+8n

Legal LTX frame count. 121 frames @ 24 fps ≈ 5.04 s. 120 snaps.

Your Spark

Docs panel that stores SPARK_HOST and friends in this browser for copy buttons.

blender-mcp

In-tree typed Blender MCP. bpy tools need blender-desk. No execute_code.

MCP

Model Context Protocol. This stack ships typed stdio servers, not Comfy Cloud MCP.

LiteGraph

Legacy canvas renderer. This studio defaults to Nodes 2.0 (Vue) instead.

Vue-corrected

workflowRendererVersion stamp for Nodes 2.0 canonical coordinates. Do not stamp Vue.

Negative Prompt Enhance

Rewrites the negative CLIP string with the positive as context. Klein stills.

Bazelisk

Contributor launcher that pins Bazel 8.4.1. Official test/lint/docs entry point.

Downloads

download-limit

Throttle Hugging Face pulls (auto = 85% of speedtest). Always clear on wrap exit.

--tier

Pack selector on one downloader. Not a studio-wide quality ladder. --limit is Mbps.

download-models

Default pack only: Klein 4B + Wan 2.2 5B + LTX-2.5 + prompt-enhance GGUF. No --tier.

download-image

Still UNET pack. Default --tier fast is Klein 4B FP8 plus TE and VAE.

download-wan

Wan pack selector. Default 5b is silent daily-driver; all skips vace and s2v.

download-ltx

LTX pack selector. Default 2.5 is the AV lab; balanced/quality are 2.3 aliases.

download-podcast

Opt-in audio packs. analog is Kokoro; acestep shares the music turbo AIO.

download-dub

Opt-in ASR + multilingual clone packs for the dub App. Not download-models.

download-music

Opt-in ACE-Step packs. turbo shares dest with podcast acestep; xl is larger.

download-3d

Opt-in TRELLIS.2 + DA3-BASE. da3-large is refused. Unload LTX first.

download-llm

enhance is the 4B GGUF already in download-models. 35B is opt-in llm-desk.

pack id

The --tier value on one downloader. Not a studio-wide quality ladder.

cache hit

Downloader skips a pack whose required files are already on MODELS_DIR.

*.incomplete

Hung Hugging Face partial. 0 MiB/s resume usually needs a drop, not a wait.

hf download

Modern Hugging Face CLI used by every pack downloader. Not huggingface-cli.

reap-models

Plan-first MODELS_DIR reclaim. --drop-pack cannot eat shared VAEs.

--drop-incomplete

Delete stuck Hugging Face *.incomplete files then re-pull. Keeps finished weights.

clear-hf-locks

Remove stale Hugging Face .lock files under MODELS_DIR. Not while hf is writing.

Hardware and safety

DGX Spark

NVIDIA Grace Blackwell desktop this stack targets. One GPU, often operated over SSH.

GB10

Spark GPU with ~128 GiB unified memory shared by OS, SSH, Docker, and Comfy.

unified memory

CPU and GPU share one memory pool on GB10. Weight copies can double unless patched.

occupancy

One heavy GPU job. Park Comfy for blender-desk or llm-desk; stop those before TRELLIS/LTX.

headroom

Free host RAM/disk checked before start so SSH still works under load.

restart: no

Compose never auto-starts Comfy after reboot. Manual start only (type yes).

disk-wizard

Guided host reclaim. Default --plan. Does not replace cleanup or reap-models.

quarantine

Move-aside instead of delete so a leftover pack can be restored.

HTB

Kernel traffic shaping used by download-limit. Often missing on Spark; then the wrap soft-fails.

MODELS_DIR

Host weight cache (default /mnt/models). Bind-mounted into Comfy. Never baked into the image.

COMFY_OUTPUT_DIR

Host folder for PNG/MP4 (default /mnt/comfy-output). Container path /outputs.

comfy-state

Docker volume for the Comfy install (venv, custom nodes). cleanup DELETE removes this only.

GHCR

GitHub Container Registry. Default start pulls a branch-aligned us-safe-studio image.

US-safe

Local weights this lab will download for a US casual-commercial operator. Not legal advice.

manage.sh

Operator CLI: setup, doctor, download-models, start (type yes), stop, status.

doctor

Preflight: Docker, GPU, RAM/disk, dirs, license one-liner, image tag, timing.

HF_TOKEN

Hugging Face token in .env. Required for gated LTX-2.5. Not a license click by itself.

gated model

Hugging Face repo that requires a license click plus a token. LTX-2.5 is gated.

Comfy Kitchen

Default attention backend (--use-ck-attention). pytorch-fallback is a 10–20× slow path.

pytorch-fallback

Slow PyTorch attention. On a real Spark this is a defect, not a default.

NVIDIA Container Toolkit

Lets Docker see the GPU. Required on the Spark host before start.

park

occupancy enter blender-desk / llm-desk POST /free; Compose may stay up.

XOR desk

One heavy GPU job. NVENC, Cycles, LTX, TRELLIS, and llm-desk XOR with each other.

us-safe-studio

GHCR tag and Compose visual profile. Weights stay on MODELS_DIR.

Path D

Laptop SSH tunnel to MCP or llm-desk. Not a fourth occupancy CLI mode.

blender-desk

Occupancy CLI mode: park Comfy (POST /free) for host Workbench dumps.

llm-desk

Occupancy CLI mode: park Comfy and run the host 35B llama-server sidecar.

three stores

GHCR image vs MODELS_DIR weights vs comfy-state volume. cleanup deletes the volume only.

Blender

Host DCC sidecar. Park Comfy (blender-desk) before Cycles CUDA or heavy dumps.

Cycles

Blender CUDA renderer. XOR with LTX, TRELLIS, NVENC, and llm-desk on GB10.

Workbench

Blender viewport / OpenGL dump path after park. Not a second CUDA denoise.

SuperSplat

Host 3DGS viewer. Not a download pack and not a Compose service.

Hugging Face

Weight host. LTX-2.5 is gated: token plus a license click as the same user.

Docker Compose

One ComfyUI service, restart no, mem_limit 90g. Not K3s.

env file

Host .env loaded by manage.sh. Session exports are for your shell and the docs panel.

SSH

How you reach a remote Spark. Headroom, restart no, and download-limit exist so this stays up.

ffmpeg

Host binary for concat, loudnorm, overlays, animatic, and audio-still-video. Hard fail if missing.

NCCL

Multi-GPU collective. This sample stack does not ship it. Independent Sparks share MODELS_DIR only.

--highvram

Wrong Comfy flag on GB10 unified memory. Do not pass it.

snap Docker

Wrong Docker install on Spark. Prefer apt docker-ce plus the Compose plugin.

mem_limit

Compose memory cap (90g) so the host keeps RAM for SSH. Do not raise it for demos.

llama.cpp

GGUF runtime. Prompt Enhance is CPU-only; llm-desk uses host llama-server.

llama-server

Host 35B OpenAI-compatible server on 127.0.0.1:30000. Occupancy llm-desk.

Docker CE

Preferred Docker engine on Spark (apt). Snap Docker is the wrong install.

spark-timing

Lab timing recorder. Refuses unless Kitchen attention is live on a real Spark.

sch_htb

Kernel HTB module wondershaper needs. Often missing on Spark; wrap then soft-fails.

cleanup

manage.sh cleanup: type DELETE. Removes the comfy-state volume only, never MODELS_DIR.

Film

last-frame continuity

Shot N's last PNG becomes shot N+1's I2V start. How 90s films work without a 90s denoise.

OTIO

OpenTimelineIO JSON for Kdenlive/Shotcut. Host-side; never in the Docker image.

NVENC

Hardware encoder for proxies/previews. Comfy must be stopped (encoder contention on GB10).

film-accept

Fail-closed gate: 5.00 s, 1280×704, LTX audio present before concat.

jobstore

Per-film state.json + shot MP4s under COMFY_OUTPUT_DIR/films/<slug>/ for resume.

Shot card

Per-shot YAML extras: script, camera, clay required, audio policy, stems.

overlay-qc

50% blend of clay first.png vs Klein look plate. Fail-closed 1280×704.

film-animatic

Cheap 90s pacing gate from clay.mp4 or held stills. Host ffmpeg.

loudnorm

ffmpeg loudness pass. Comfy has no LUFS node. Podcast default −16; YouTube −14.

sidecar

Host process (Blender, SuperSplat, NLE), not a Compose service. Occupancy with Comfy.

Spark farm

Independent Sparks as parallel 5 s workers with one weight copy. No NCCL.

concat-shots

Host ffmpeg stitch for 5 s takes. In-graph EZFilmConcat is the one-click 90s path.

print-shot

Host jobstore verb: Queue one 5.00 s LTX/Wan take and write state.json.

film-resume

Skip ok 5.00 s shots in the jobstore after a dropped SSH session.

take-promote

Promote a keeper take into the film jobstore. Does not rewrite masters silently.

world-only

Shot audio policy: keep LTX joint-AV bed, no stem mix. Fail-closed default on lab YAML.

picture-lock

Picture is accepted; now mix stems. Occupancy audio — stop Klein/Wan/LTX first.

film-proxies

NVENC preview proxies. Refuse while Compose is up. Never rewrite masters.

Kdenlive

Host NLE that can import the OTIO JSON. Occupancy: stop Comfy if it will use the GPU.

Shotcut

Host NLE for the OTIO export. Same occupancy rule as Kdenlive.

Audio

Local dub

Clone-and-translate a recorded show into a duration-locked second audio track.

YouTube multi-language audio

YouTube Studio Languages tab: upload an audio-only dub the same length as the video.

stem-mix

Picture-lock mix: DX / BG / FX / MX, duck −15 dB, YouTube loudnorm −14 LUFS.

audio-still-video

Mux a FLAC/MP3 master with a still into a YouTube MP4. Host ffmpeg.

TTS

Text-to-speech. Lab default is Kokoro ONNX/CPU, not a cloud voice API.

disclosure bumper

Spoken line that the podcast graph prepends: voices and music are synthesized.

learning episode

Paste notes and links, pick format and duration, Queue a local study podcast.

PerTh

Chatterbox implicit watermark. Stays on. Needs setuptools<82 (pkg_resources).

faster-whisper

CTranslate2 ASR used by local dub. Needs the full dir, not model.bin alone.

Silero VAD

Voice-activity ONNX used before faster-whisper in the dub ASR pack.

ASR

Automatic speech recognition. Dub default pack: Silero VAD + faster-whisper.

pkuseg

Chinese segmenter zip for Chatterbox Multilingual. Lives under MODELS_DIR/pkuseg.

duration lock

Dub mix matches source length: pitch-preserve up to 1.25×, then spill, then fade-trim.

Clone CFG

Chatterbox language-transfer knob. Dub auto 0.3 on EN→ES (retry 0.5). CFG 0 often has no words.

LUFS

Loudness units. Podcast default −16; YouTube −14. Comfy has no LUFS node — ffmpeg loudnorm.

Licenses

Apache 2.0

License on default Klein 4B and Wan 2.2 (and several opt-in packs). Redistribute NOTICE with weights.

LTX Community License

LTX-2.5 terms: free commercial under $10M COMPANY revenue (affiliates count); disclose AI; no distill.

MiniMax H3

Banned. US Excluded Territory for weights and outputs. download-h3 aliases are refused.

FLUX.2-dev

FLUX Non-Commercial 32B. Opt-in `--tier flux2-dev`. Not the lab default.

Klein 9B

FLUX Non-Commercial 9B. Opt-in `--tier 9b`. Distilled 4B Apache is the lab default.

DreamX-World

Refused. download-dreamx is Apache Creator only.

DA3-LARGE

Refused depth weight. DA3-BASE Apache is the allowed sidecar.

Seedance

Banned video graph family. promote-workflow refuses it.

Kling

Banned cloud/video graph family. Not a lab default.

Wav2Lip

Banned lip-sync OSS. Lab talking-head is LTX audio freeze, not mouth-sync.
