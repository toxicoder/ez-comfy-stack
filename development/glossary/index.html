    Glossary¶

    What's on this page

    • How dotted terms and the definition dialog work
    • Every studio, model, and operator term in one place
    • Links from each entry to the guide that teaches it

    What this enables

    • Looking up Klein, Wan, LTX, Queue, latent, headroom, and the rest without leaving the page
    • Teaching vocabulary once so Create and Operate pages can stay task-focused

    Dotted words open a definition

    Across the docs, the first time a glossary term appears on a page it is underlined with dots.

    • Hover (or keyboard focus) to read the short definition
    • Click or press Enter / Space to open the dialog
    • Open full glossary entry jumps here
    • Esc or the backdrop closes the dialog

    Terms inside code, headings, and links stay plain so copy-paste and navigation do not fight the modal.

    flowchart LR
  Prose["Docs prose"] --> First["First match on the page"]
  First --> Hover["Hover: short definition"]
  First --> Click["Click: dialog"]
  Click --> Full["This page: long entry"]

    Add or change a term in includes/glossary.json (unique id and aliases). Conventions: Project conventions.

    Models¶

    Klein 4B¶

    FLUX.2 Klein 4B distilled FP8 is the default still engine in this studio. Distilled means quality is almost entirely the positive prompt: 4 steps, CFG 1.0, Qwen3-4B CLIP (flux2). Klein 9B is FLUX Non-Commercial and is not the lab default. See Klein, Wan, and LTX and Prompting.

    Also called: FLUX.2 Klein 4B, FLUX.2 Klein, Klein

    See also: T2I · Qwen3-4B · Wan 2.2 · LTX-2.5 · Prompt Enhance

    Wan 2.2¶

    Wan 2.2 TI2V-5B is the silent motion lane. I2V prompts should be motion + one camera move — the start image owns look. Do not prompt audio or a score. Optional A14B and Fun InP packs are not part of download-models. See Klein, Wan, and LTX.

    Also called: Wan 2.2 5B, TI2V-5B, Wan

    See also: I2V · T2V · UMT5-XXL · LTX-2.5 · ping-pong

    LTX-2.5¶

    LTX-2.5 distilled INT8-convrot is the AV hero. Lab graphs load an audio VAE, concat empty audio latents with video latents, then decode audio into VHS so the MP4 has world sound. Landscape size is 1280×704 (VAE ÷32), not 1280×720. Accept the Hugging Face license and set HF_TOKEN before download-models. See Model licenses.

    Also called: LTX

    See also: joint AV · I2V · LTX Community License · gated model · VideoHelperSuite

    Qwen3-4B¶

    Klein stills encode prompts with qwen_3_4b as CLIP type flux2. Comfy wraps the string in a Qwen chat template — do not paste <|im_start|> into the widget. A separate Qwen3-4B-Instruct GGUF rewrites lazy sentences when Prompt Enhance is on (CPU-only). See Prompting.

    Also called: qwen_3_4b, Qwen3

    See also: Klein 4B · CLIP · GGUF · Prompt Enhance

    UMT5-XXL¶

    Wan graphs load UMT5-XXL as CLIP type wan. T2V wants Entity + Scene + Motion + Aesthetic + one camera verb. I2V should drop look language so the start image stays in charge. See Prompting.

    Also called: UMT5

    See also: Wan 2.2 · CLIP · T2V · I2V

    Gemma 4¶

    Seeded LTX graphs use CLIPLoader gemma4-12b-with-proj-ltx-2.5-comfy-int8-convrot with type ltxv. A DualCLIP or LTX-2.3 encoder on a 2.5 graph throws embedding-size errors. Write one present-tense paragraph with sound interleaved. See Prompting.

    Also called: Gemma4

    See also: LTX-2.5 · CLIP · joint AV

    ACE-Step¶

    Native ACE-Step 1.5 ships in the Comfy pin. Podcast beds stay instrumental; rap graphs send original lyrics. download-music --tier turbo and download-podcast --tier acestep share the same AIO file. Occupancy: stop Klein/Wan/LTX first. See Local music and Local podcast.

    Also called: ACE-Step 1.5

    See also: occupancy · Kokoro · TTS

    Kokoro¶

    Kokoro-82M is the US-safe default TTS (opt-in download-podcast --tier analog). Voices are stock identities, not clones of real people. The disclosure node prepends the spoken bumper so you do not type it. See Local podcast.

    Also called: Kokoro-82M

    See also: TTS · ACE-Step · disclosure bumper

    Chatterbox¶

    Chatterbox Turbo is an opt-in TTS (download-podcast --tier chatterbox). Keep the PerTh watermark. Do not add celebrity reference WAVs. Kokoro remains the Spark-safe default. See Local podcast.

    See also: Kokoro · TTS · Local dub

    Chatterbox Multilingual¶

    Default engine for Local dub. Cross-lingual clone from a short ref extracted from this job, not a celebrity pack. Needs from_local(..., t3_model="v3") (GitHub pin CHATTERBOX_TTS_REF; PyPI 0.1.7 is too old) and setuptools<82 so PerTh (perth.PerthImplicitWatermarker) stays importable. Turbo English remains download-podcast --tier chatterbox.

    Also called: Chatterbox Multilingual V3

    See also: Chatterbox · Local dub · TTS

    CLIP¶

    In this studio, “CLIP” means the model-specific text encoder: Qwen (flux2) for Klein, UMT5 (wan) for Wan, Gemma4-with-proj (ltxv) for LTX. Wrong CLIP type is a common Queue failure. See Image and video generation.

    See also: Qwen3-4B · UMT5-XXL · Gemma 4 · KSampler

    VAE¶

    A VAE compresses an image or video into latents and decodes latents back to pixels (and, for LTX, audio). Mixing a Wan VAE with an LTX graph will fail. LTX also needs the audio VAE so joint AV latents are not length-zero. See Image and video generation.

    See also: latent · LTX-2.5 · Klein 4B · Wan 2.2

    UNET¶

    Comfy loaders still say UNET for many diffusion transformers, including Klein and Wan. The filename on the canvas must match a weight under MODELS_DIR. Lab graphs pin those names; do not swap in Klein 9B or FLUX.2-dev. See Models and cache.

    See also: KSampler · latent · MODELS_DIR

    GGUF¶

    download-models places Qwen3-4B-Instruct-2507-Q4_K_M.gguf under comfy/llm/. Prompt Enhance runs it CPU-only (n_gpu_layers=0) so it does not fight LTX for GB10 memory. Missing GGUF is fail-soft: generation still runs. See Prompting.

    See also: Prompt Enhance · Qwen3-4B · occupancy

    MagCache¶

    MagCache skips some denoiser steps on the Wan 5 s smoke graph (extra.lab_magcache). Hero LTX prints and A14B graphs leave it off. If the node is missing, the Wan graph still Queues. See Workflow catalog.

    See also: Wan 2.2 · I2V

    Nunchaku¶

    LAB_VISUAL_ENABLE_NUNCHAKU=0. Seeded Klein graphs use core UNET/CLIP/VAE loaders. Do not pip install nunchaku from PyPI (that is a stats library). aarch64 Spark wheels are skip-by-default. See Troubleshooting.

    See also: Klein 4B · UNET

    SeedVR2¶

    SeedVR2-3B is a post-concat restore (download-restore --tier seedvr2-3b). Conservative 1.3–1.5× on the master only. Occupancy: stop Comfy first if you restore on GPU. See 90s shorts.

    Also called: SeedVR2-3B

    See also: occupancy · last-frame continuity

    TRELLIS.2¶

    download-3d --tier trellis2 pulls TRELLIS.2 native weights only. Never pip-install nvdiffrast/nvdiffrec. Stop the Comfy stack before a heavy 3D job. See Studio sidecars.

    Also called: TRELLIS

    See also: sidecar · occupancy · DA3-BASE

    DA3-BASE¶

    Depth Anything 3 BASE is the allowed depth sidecar weight. --tier da3-large is banned. Same occupancy rule as TRELLIS: one heavy GPU job. See Studio sidecars.

    Also called: DA3

    See also: TRELLIS.2 · occupancy

    LongCat-Video¶

    download-longcat --tier video is opt-in. Context-parallel needs an explicit allow flag. Independent Sparks still share MODELS_DIR; this sample stack does not ship in-tree NCCL. See Spark farm.

    Also called: LongCat

    See also: Spark farm · Wan 2.2

    DreamX-Creator¶

    download-dreamx --tier creator only. Unload LTX/Wan 5B first. Not a lab default and not a 90s printer. See Model licenses.

    Also called: DreamX

    See also: joint AV · LTX-2.5

    Fun InP¶

    download-wan --tier fun-inp then load wan-flf-5s-lab-example. Unload LTX first. This is a continuity draft, not the 90s LTX print path. See 90s shorts.

    See also: first-last-frame · Wan 2.2 · VACE

    VACE¶

    VACE stitches the last frame of shot A toward the first frame of shot B as a short join clip. It is a Comfy graph, not a Docker sidecar. See Studio sidecars.

    See also: Fun InP · last-frame continuity · Wan 2.2

    Z-Image Turbo¶

    Z-Image Turbo uses different weights (ae, z_image_turbo_*). Seeded lab stills are Klein 4B. If a template asks for ae.safetensors, you loaded the wrong graph — open klein-still-draft-lab-example. Optional: download-image --tier zimage. See Model licenses.

    Also called: Z-Image

    See also: Klein 4B · T2I

    VideoHelperSuite¶

    Wan and LTX lab graphs wire VHS_VideoCombine with save_output: true. After Queue, open Save video (MP4) — open node for preview. Files land on the host at COMFY_OUTPUT_DIR. LTX also feeds decoded audio into VHS. See Still to motion to AV.

    Also called: VHS_VideoCombine, VHS

    See also: LTX-2.5 · Wan 2.2 · COMFY_OUTPUT_DIR

    Qwen3-TTS¶

    download-podcast --tier qwen3tts is opt-in. Empty reference audio stays on Kokoro. Do not use it to clone a real person. See Local podcast.

    See also: Kokoro · TTS

    FP8¶

    FP8 keeps the default Klein 4B and several Wan files small enough for GB10. It is a storage/compute format, not a style. NVFP4 Klein is optional and still Apache for 4B. See Models and cache.

    See also: Klein 4B · INT8-convrot

    INT8-convrot¶

    Lab LTX-2.5 filenames include int8-convrot. If INT8-convrot or gated access fails, LTX-2.3 distilled FP8 is an optional fallback — seeded graphs still expect 2.5 names. See Models and cache.

    See also: LTX-2.5 · FP8

    Modalities¶

    T2I¶

    Text-to-image is the first studio move. Queue klein-still-draft-lab-example, then feed a PNG into Wan or LTX I2V if you want motion. See ComfyUI basics.

    Also called: text-to-image

    See also: Klein 4B · I2V · Queue

    I2V¶

    Wan I2V is silent; LTX I2V can carry world audio. Point LoadImage at ez_still_draft_*.png (or a hero 1280×704 still for LTX). Do not re-describe wardrobe and location in an I2V prompt. See Klein, Wan, and LTX.

    Also called: image-to-video

    See also: T2V · LoadImage · Wan 2.2 · LTX-2.5

    T2V¶

    Use T2V when you do not have a still you want to keep. Lab Wan T2V bypasses LoadImage. LTX T2V still wants a flowing paragraph with sound. See Prompting.

    Also called: text-to-video

    See also: I2V · Wan 2.2 · LTX-2.5

    A2V¶

    klein-talking-head-lab-example smokes LTX A2V freeze. Banned lip-sync OSS (Wav2Lip) stays out. See Workflow catalog.

    Also called: audio-to-video

    See also: S2V · LTX-2.5

    S2V¶

    Wan S2V is opt-in (download-wan --tier s2v) and occupancy-heavy. Talking-head lab graphs mention it; they do not require it for the LTX freeze smoke. See Model licenses.

    Also called: speech-to-video

    See also: A2V · Wan 2.2

    joint AV¶

    LTX is a joint audio/video model. Lab graphs must build empty audio latents and concat them before KSampler. Omitting that path yields a reshape error on length-zero audio. Wan stays silent on purpose (cleaner Apache motion). See Klein, Wan, and LTX.

    Also called: AV hero

    See also: LTX-2.5 · Wan 2.2 · VideoHelperSuite

    first-last-frame¶

    FLF is a continuity draft: you pick how the shot starts and ends. It is optional and large. 90s films instead chain last-frame PNG → next I2V start. See 90s shorts.

    Also called: FLF

    See also: Fun InP · last-frame continuity · I2V

    ping-pong¶

    wan-gif-loop-lab-example leaves VHS ping-pong on. Prompt cyclic motion (breeze, curtains), not a walk or one-way dolly, or reverse playback looks wrong. See Prompting.

    See also: Wan 2.2 · VideoHelperSuite

    Studio¶

    Asset Bible¶

    Each slug is an ez.asset.v1 record (kind, prompt, seed, pipeline, takes). scene.json instances slugs; it does not embed meshes. Gen is Klein still → TRELLIS.2. Construct is a shopping list of primitives + HDRI + bible refs. Operator verb today: asset-ls. See Asset Bible.

    Also called: asset-bible

    See also: Klein 4B · LTX-2.5 · TRELLIS.2

    ComfyUI¶

    You operate the host with manage.sh; you use the studio in the browser at COMFY_PORT (default 8188). Graphs are nodes and widgets, not a chat box. Seeded files end in -lab-example and copy into user/default/workflows/ on start. App Mode graphs land as *.app.json so they appear under Apps as well as Workflows. See ComfyUI basics.

    See also: Queue · widget · workflow · manage.sh

    workflow¶

    Host files live under workflows/*-lab-example.json. The entrypoint copies them into Comfy (*.app.json when App Mode is the default view). Do not edit raw JSON for daily use; type on the canvas. Every lab graph includes a Note node. See Workflow catalog.

    Also called: node graph, lab graph

    See also: lab-example · Note node · widget · ComfyUI

    Queue¶

    Queue is the studio's play button. A still-draft Queue is minutes; a 5 s Wan/LTX Queue is minutes; a one-click 90s film Queue is 18 sequential 5 s prints (long wall-clock, not a 90s denoise). See ComfyUI basics.

    See also: ComfyUI · KSampler · seed

    widget¶

    Studio work is widget work: change the Positive prompt, seed, LoadImage filename, or Enhance toggle on the canvas. The JSON on disk stays the seeded lab example. See ComfyUI basics.

    See also: Queue · workflow · Enhance · App Mode

    App Mode¶

    App Mode shows the creator widgets listed in extra.linearData (Prompt, Style, Rewrite prompt, seed; LoadImage on I2V; size/UNET only on the daily still). Persist is [nodeId, widgetName, config] with an integer node id — frontend 1.49.6+ upgrades that to a live WidgetId. Two-part 11:prompt ids are dropped and the side panel looks empty. It is not a second frontend. The lab contract is lab_app_mode. Multi-shot Apps expose one identity prompt, not per-shot cards. Film graphs may open in graph view. On start, App Mode graphs seed as *.app.json so they appear in Comfy's Apps sidebar as well as Workflows. See ComfyUI Apps and ComfyUI basics.

    See also: lab_app_mode · widget · occupancy · workflow

    lab_app_mode¶

    extra.lab_app_mode marks a seeded graph as an App (enabled, default_view, lane inspire/produce/audio/film/dcc/optional, occupancy, handoff). default_view: app seeds as *.app.json (Apps + Workflows sidebars). Do not require extra.linearMode — Comfy upstream does not write it. See ComfyUI Apps.

    See also: App Mode · occupancy · lab-example

    latent¶

    5.00 s at 24 fps is 120 frames (some smokes use 121 = 4n+1). LTX spatial size must be divisible by 32 — lab landscape is 1280×704. Do not Queue a 30–90 s latent on GB10. See Image and video generation.

    Also called: latent space

    See also: VAE · KSampler · LTX-2.5

    KSampler¶

    Distilled Klein uses 4 steps and CFG 1.0. Wan/LTX lab graphs pin steps, scheduler, and frame count on the canvas. Changing those widgets is how you experiment; changing them to a 90 s denoise is how you melt the Spark. See Image and video generation.

    Also called: sampler

    See also: CFG · seed · latent · Queue

    CFG¶

    CFG 1.0 on distilled Klein means the positive prompt is the whole game. FLUX-family models do not use negatives well; put constraints in the positive (“unmarked facades”). See Prompting.

    See also: Klein 4B · KSampler

    seed¶

    Fix a seed when you iterate a prompt so lighting and identity do not jump. Identity sheets pin seed 42. Random seeds are for discovery, not for matching a still into I2V. See ComfyUI basics.

    See also: Queue · identity still

    Prompt Enhance¶

    Klein/Wan/LTX Prompt Enhance defaults on for lazy CLIP printers and identity bibles you type. Seeded graphs pin it off for 90s films, talking-head, loops, camera-verb I2V, podcast scripts, and ACE tags/lyrics so the rewriter cannot mutate those inputs. The CLIP prompt box is visible on the node; after Queue it is the encoded string. Fail-soft if the GGUF is missing. See Prompting.

    See also: Enhance · GGUF · Qwen3-4B

    world bible¶

    Dream-house and style-lock graphs keep massing, materials, and inventory in a bible. Shot cards add a new camera (lock=view) or change only light (lock=state). Each view shot names its own room backdrop so interiors do not reuse one skyline. Identity-mode enhance keeps the bible camera-free. See Prompting.

    See also: identity still · Prompt Enhance

    identity still¶

    90s films Queue a Klein identity at 1280×704 (LTX grid), then 18 LTX prints that start from last frames. Enhance stays off so the rewriter cannot restyle the bible. See 90s shorts.

    See also: Klein 4B · world bible · last-frame continuity

    lab-example¶

    If it does not end in -lab-example, it is not a lab smoke. Optional packs live under workflows/optional/ and workflows/shorts/. See Workflow catalog.

    Also called: lab-example graphs

    See also: workflow · Note node

    Note node¶

    Every seeded graph includes a Comfy Note plus extra.lab_note. Read it before you Queue. It is the UI source of truth when docs and widgets disagree after a pull. See ComfyUI basics.

    See also: lab-example · workflow

    LoadImage¶

    After a still-draft Queue, set Wan/LTX LoadImage to ez_still_draft_*.png under COMFY_OUTPUT_DIR (the container sees /outputs). Leaving example.png is a smoke test only. See Still to motion to AV.

    See also: I2V · COMFY_OUTPUT_DIR

    Enhance¶

    Enhance defaults on for every lab graph. Turn it off to pin widget text. Identity mode keeps world bibles camera-free. I2V / FLF / VACE ignore style — the start frames own look. See Prompting.

    See also: Prompt Enhance · world bible

    Research Chat¶

    No-UNET creative-process desk (research-chat-lab-example). Queue a Message; read Reply and Sources. Mode research runs a planner plus 1–3 sequential search workers, then a synthesizer brief (prompt ingredients → Prompt Forge → Spark Still). Same on-box Qwen3-4B GGUF as Prompt Enhance (n_gpu_layers=0). HTTPS search is SSRF-safe. Laptop Path D: ./scripts/manage.sh research-mcp --stdio. See ComfyUI Apps and Occupancy desk.

    Also called: research-chat, research-chat-lab-example

    See also: Prompt Enhance · occupancy · Qwen3-4B

    research-mcp¶

    Typed stdio MCP (./scripts/manage.sh research-mcp). Tools: occupancy_status, list_lab_apps, describe_app, chat, web_search, research. Does not Queue Comfy, does not refuse a GPU session, does not map idle to blender-desk. No arbitrary URL fetch. Official Comfy Cloud MCP is out of tree. See Occupancy desk.

    See also: Research Chat · occupancy

    Guide pack¶

    The DCC ↔ Comfy print handshake. Lives under ${COMFY_OUTPUT_DIR}/guides/<slug>/<shot>/. Size is the LTX VAE grid (1280×704 or 768×1280, never 1280×720). 120 frames @ 24 fps. Workbench clay + mist depth + outline canny. Occupancy XOR: stop Comfy before export-guides. See DCC guide pack.

    Also called: guide pack, guide-pack, DCC guide pack

    See also: LTX-2.5 · occupancy · sidecar

    house-views¶

    Host Blender constructs a bpy-primitive set under ${COMFY_OUTPUT_DIR}/assets/sets/<slug>/ (layout, GLB, clay, depth). Size is Instagram 4:5 (1024×1280), not the LTX guide pack. Stop Comfy first for the dump. manage.sh start seeds LoadImage plates (copy pack or render layout) so klein-dream-house-clay-lab-example can Queue without Blender. Language-only tour → klein-dream-house-lab-example. See Dream-house tours.

    Also called: dream-house clay, clay tour

    See also: Guide pack · occupancy · sidecar · Klein 4B

    blender-stills¶

    Host Blender dumps ez.guide.still.v1 under ${COMFY_OUTPUT_DIR}/guides/<slug>/stills/<plate>/. Sizes: 1280×704, 768×1280, 1024×1280, 1024×1024, 1280×720 (thumb, not LTX). Not the 5.00s shot pack and not house-views. Park Comfy (occupancy enter blender-desk) first. --install-inputs copies first.png into input/ while compose may stay up. Apps: klein-from-clay-plates, klein-from-canny. See Blender creator suite.

    Also called: still pack, ez.guide.still.v1

    See also: Guide pack · house-views · occupancy · sidecar · Klein 4B

    Hardware and safety¶

    DGX Spark¶

    ez-comfy-stack is a sample studio for a single DGX Spark. Independent Sparks may share MODELS_DIR (Spark farm) but there is no in-tree NCCL. SSH recoverability drives restart: no, headroom, and download-limit. See Hardware, memory, and safety.

    Also called: Spark

    See also: GB10 · headroom · Spark farm · restart: no

    GB10¶

    There is no separate giant VRAM pool. Compose mem_limit is 90g so the host keeps headroom for SSH. One heavy job at a time. See Hardware, memory, and safety.

    See also: unified memory · headroom · occupancy

    unified memory¶

    The stack applies patch_unified_memory_copy.py (copy=False on safetensor .to(device)) and patch_get_free_memory.py (host free RAM instead of under-reporting cudaMemGetInfo). --highvram is the wrong flag here. See Hardware, memory, and safety.

    See also: GB10 · headroom · Comfy Kitchen

    occupancy¶

    GB10 is one GPU. occupancy enter blender-desk parks Comfy (POST /free) for host Workbench dumps. occupancy enter llm-desk parks Comfy and starts the host 35B llama-server (127.0.0.1:30000). NVENC/proxies still want Compose down. Do not load Klein + Wan + LTX + TRELLIS + llm-desk in one session. App occupancy keys (none/llm/klein/wan/ltx/film/audio/trellis) are graph labels — llm is not a CLI mode. See Occupancy desk and Studio sidecars.

    See also: sidecar · ACE-Step · GB10 · App Mode

    headroom¶

    doctor and start refuse when host free RAM is below policy (min_host_free_gib). Do not weaken this for demos. See Reboot safety and Hardware, memory, and safety.

    See also: restart: no · doctor · unified memory

    restart: no¶

    A remotely managed Spark that relaunches a 90g GPU job on boot is how you lose SSH. Always manage.sh stop before reboot. Independent farm nodes use the same policy. See Reboot safety.

    Also called: restart: "no"

    See also: headroom · manage.sh · DGX Spark

    download-limit¶

    Full-rate multi-GB pulls freeze SSH. download-models wraps wondershaper when HTB works, else gentler HF workers. DOWNLOAD_LIMIT=off is an SSH risk. See Download limit.

    Also called: download limit

    See also: HTB · headroom · MODELS_DIR · --tier

    --tier¶

    download-models has no --tier. Image fast, Wan 5b, and LTX 2.5 are three different pack ids that happen to be the lab defaults. Wan --tier all does not include vace or s2v. See Download tiers.

    See also: download-models · download-limit · MODELS_DIR

    download-models¶

    Does not pull podcast, music, 3D, LongCat, DreamX, or SeedVR2. Those are opt-in utilities with their own --tier pack ids. Throttled by download-limit. See Download tiers and Models and cache.

    See also: --tier · download-limit · MODELS_DIR

    disk-wizard¶

    Surveys MODELS_DIR junk, Hugging Face hub cache, Docker build cache, Ollama/vLLM leftovers, and other experiment residue on a Spark that runs more than this studio. --plan is read-only. Review-class items quarantine. Never docker system prune -a --volumes. cleanup still only removes the comfy-state volume. See Disk wizard.

    Also called: disk wizard

    See also: quarantine · MODELS_DIR · download-models

    quarantine¶

    reap-models --quarantine and disk-wizard review-class actions move files to a timestamped tree with a JSONL manifest. Restore with the matching restore --from command. Junk class may delete in place. See Disk wizard.

    See also: disk-wizard · MODELS_DIR

    HTB¶

    When sch_htb is absent, downloads continue with a warning and gentler Hugging Face settings. That is not a license to set DOWNLOAD_LIMIT=off. See Download limit.

    Also called: wondershaper

    See also: download-limit

    MODELS_DIR¶

    Weights live on the host so GHCR images stay small and multiple stacks can share one cache. cleanup does not delete MODELS_DIR. See Models and cache.

    See also: comfy-state · GHCR · COMFY_OUTPUT_DIR

    COMFY_OUTPUT_DIR¶

    cleanup does not delete outputs. status prints the path. Look here after Queue, not inside the git repo. See Getting Started.

    See also: MODELS_DIR · VideoHelperSuite

    comfy-state¶

    First start seeds the volume from /opt/comfy-prebuilt. Weights are not in this volume. Resetting it does not re-download Klein/Wan/LTX. See Hardware, memory, and safety.

    See also: GHCR · MODELS_DIR

    GHCR¶

    main → ghcr.io/toxicoder/ez-comfy:us-safe-studio; development and feature branches → -development. The image has Comfy+torch, not Klein/Wan/LTX weights. Old flux-to-ltx* tags freeze. See Getting Started.

    See also: comfy-state · MODELS_DIR

    US-safe¶

    Defaults: Apache Klein 4B + Apache Wan 2.2 + LTX-2.5 Community (gated, $10M cap). MiniMax H3 is a US Excluded Territory ban for weights and outputs. Read Model licenses before a 30 GB pull.

    See also: LTX Community License · Apache 2.0 · MiniMax H3

    manage.sh¶

    Run from the repo root. It loads .env. Studio users still Queue in the browser; operators keep SSH alive with this tool. Full catalog: manage.sh reference.

    See also: doctor · restart: no · download-limit

    doctor¶

    Fix hard doctor failures before download-models. Missing lab weights are a warning, not a hard fail. attention: pytorch-fallback on a running Spark is a 10–20× slow path. See Troubleshooting.

    See also: manage.sh · headroom · Comfy Kitchen

    HF_TOKEN¶

    Klein 4B and Wan 5B are Apache. LTX-2.5 still needs you to open the model card as that user and click Agree. Fine-grained tokens need gated-repo read. See Model licenses.

    See also: gated model · LTX-2.5

    gated model¶

    A token in .env is not the same as accepting the Lightricks license. download-models exits non-zero until the distilled LTX set is on disk. See Getting Started.

    Also called: gated repo

    See also: HF_TOKEN · LTX-2.5 · LTX Community License

    Comfy Kitchen¶

    doctor prints attention: kitchen|sage|pytorch-fallback|unknown. Never pass --use-sage-attention next to Kitchen. spark-timing refuses to record unless Kitchen is live. See Hardware, memory, and safety.

    Also called: Kitchen attention

    See also: pytorch-fallback · doctor

    pytorch-fallback¶

    If doctor says attention: pytorch-fallback while compose is up, do not record spark-timing and do not treat mushy video as a prompt problem. See Troubleshooting.

    See also: Comfy Kitchen

    setup --install-docker configures nvidia-ctk when present. Snap Docker is the wrong install. See Getting Started.

    Audio¶

    Local dub¶

    The dub-localize-lab-example App transcribes with faster-whisper (segments become turns), clusters speakers with Chatterbox ve.pt, writes per-speaker clone refs, translates each turn with the on-box GGUF (ISO source → target), and clones each voice (Chatterbox Multilingual V3, language_id like es). Pick or upload a file from input/ (or set a Source URL). I have rights must be on. Occupancy audio. After Queue, Dub status lists speaker/turn counts and translated N/M. Missing ASR, clone, llama.cpp, or GGUF yields an empty mix plus that status, not the original recording and not English cloned as the target. Wheels install separately (Chatterbox GitHub zip --no-deps so torch 2.14 stays; PyPI 0.1.7 has no t3_model=v3). YouTube Studio wants the audio-only ez_dub_yt file, not a muxed multi-track MP4. See Local dub.

    Also called: dub-localize

    See also: Chatterbox · TTS · occupancy · disclosure bumper · YouTube multi-language audio

    YouTube multi-language audio¶

    YouTube does not reliably ingest extra AAC tracks muxed into an MP4. Export ez_dub_yt.wav, upload it under Languages → Audio, add the translated SRT, and use the synthetic/altered-content toggle. Eligibility varies by channel. See Local dub.

    Also called: multi-language audio, MLA

    See also: Local dub · loudnorm

    stem-mix¶

    LTX joint AV is the world bed, not the master. Occupancy audio — stop Klein / Wan / LTX first. film-accept checks stem LUFS when audio_policy: stems. See Clay to finish.

    Also called: audio finish

    See also: loudnorm · film-accept

    audio-still-video¶

    Post-Queue export only. Rap / podcast / dub graphs still save FLAC + MP3. manage.sh audio-still-video --audio FILE --image FILE loops the still (libx264, 1920×1080 letterbox default, AAC, +faststart). CPU encode; compose may stay up. Missing ffmpeg is a hard fail. See Local music.

    See also: loudnorm
