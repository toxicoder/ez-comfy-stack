    Troubleshooting — studio canvas¶

    What's on this page

    • Studio-user symptoms on the Comfy canvas (Missing Models, LTX 720, dub, DCC dumps)
    • Occupancy XOR — park vs stop, sidecar contention, splat/Blender park-first
    • studio-ui board on :8190 vs App Mode on ${COMFY_PORT}

    What this enables

    • Unblocking Queue, preview, and dump failures from the canvas
    • Keeping one heavy GPU job on GB10 (park for dumps; stop for SuperSplat/NVENC)

    One heavy GPU job

    GB10 is XOR. Park with ./scripts/manage.sh occupancy enter blender-desk for Workbench dumps; ./scripts/manage.sh stop for SuperSplat/NVENC. Do not Queue LTX next to Blender, TRELLIS, ACE-Step, or the 35B sidecar. Occupancy desk.

    Studio user (canvas)¶

    Symptom Likely cause Action
    Missing Models on a seeded lab graph Weights not on MODELS_DIR / broken comfy/ symlink ./scripts/manage.sh download-models then restart. Models and cache
    Start images vanished after cleanup LoadImage files lived on the named volume Put start frames in ${COMFY_OUTPUT_DIR}/input (container /inputs). cleanup does not delete COMFY_OUTPUT_DIR
    LTX einops / divide by 45 Width/height not ÷32 (720 or 1080) Lab size is 1280×704. ez_ltx_spatial auto-snaps; prefer typing 704
    No MP4 preview, only PNGs Old graph without VHS, or looking at SaveImage Re-open seeded wan-* / ltx-*; open Save video (MP4) node
    LTX MP4 has no sound Missing audio VAE decode → VHS Re-open current ltx/*
    Enhance did nothing GGUF / llama.cpp missing, or local LLM timed out Read Enhance status. GGUF missing → download-models then restart. llama.cpp unavailable → Llama did not import (pip “already satisfied” is not enough). Queue self-heals, then force-reinstalls the GitHub manylinux wheel. If status still has a docker exec … pip install --force-reinstall line, run it (no image rebuild). Confirm: docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'from llama_cpp import Llama'. Default timeout is 180s (EZ_LLM_TIMEOUT_S) on 8 CPU threads (EZ_LLM_N_THREADS)
    Dub Queue says rights refused I have rights is off (default) Turn it on only when you own the recording or have speaker consent. Local dub
    Dub Source file is (none) / empty source Nothing selected in the dropdown Upload media, or pick a file already in ${COMFY_OUTPUT_DIR}/input. Do not type a host path
    Dub file not in the Source dropdown File is under /outputs, or the App was open before dub-fetch Put media in ${COMFY_OUTPUT_DIR}/input (container /inputs). Reload the App. Local dub
    Dub Upload media missing Pack JS not copied, or the browser is holding an old frontend Restart the container so entrypoint copies ez_dub/js/. Hard-refresh the Comfy tab
    Dub empty mix / no transcript faster-whisper or Chatterbox missing, ASR/clone snapshot incomplete, or translation cannot run Dub status names the miss. download-dub --tier asr (needs model.bin, config.json, and tokenizer.json) then --tier clone (ve.pt, s3gen.pt, T3 V3, tokenizer JSON, Cangjie5_TC.json, conds.pt) with the stack up. Restart also heals wheels (entrypoint pip, including Chatterbox V3 t3_model). Do not pip install faster-whisper chatterbox-tts as one command — chatterbox pins torch 2.6 and blocks ASR. Do not pip install chatterbox-tts from PyPI (0.1.7 has no t3_model=v3).
    Dub status / log qwen3tts extra not installed — download-podcast --tier qwen3tts Old path named a weights command for a wheel miss (from qwen_tts import Qwen3TTSModel). Status used to spam once per turn Pull latest. New status names pip install --no-deps qwen-tts (extras einops soundfile first). Never unconstrained pip install qwen-tts (pins transformers==4.57.3). Weights/tokenizer: ./scripts/manage.sh download-podcast --tier qwen3tts (complete snapshot, not model.safetensors only). Queue fail-fasts: one Dub status, empty mix, no chatterbox fallback
    First chatterbox Queue HEADs Cangjie5_TC.json / writes /root/.pkuseg/ from_local still called Hub; pkuseg downloaded ontonotes into the container home Pull latest. download-dub --tier clone keeps Cangjie5_TC.json and seeds ${MODELS_DIR}/pkuseg. Compose sets PKUSEG_HOME=/models/pkuseg; entrypoint symlinks /root/.pkuseg. ~280 s for 7 turns on GB10 is inference, not a leftover download
    Dub status llama.cpp unavailable / English text_target Llama did not import (wheel metadata can be present). Queue used to copy source into text_target and clone English as the target Pull latest. Queue self-heals llama-cpp-python (CPU extra-index, then GitHub manylinux --force-reinstall --no-deps). If Dub status still names a docker exec … pip install --force-reinstall command, run that line. Confirm: docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'from llama_cpp import Llama'. Queue stops before ASR when Rewrite translation is on and source ≠ target (empty mix + that status).
    Dub status chatterbox-tts missing t3_model=v3 Volume still has PyPI 0.1.7 (from_local has no t3_model) Pull latest. Restart or download-dub --tier clone with the stack up (force-reinstalls the GitHub zip --no-deps). Confirm: from inspect import signature; from chatterbox.mtl_tts import ChatterboxMultilingualTTS; 't3_model' in signature(ChatterboxMultilingualTTS.from_local).parameters.
    Dub status resemble-perth watermarker missing / chatterbox failed: 'NoneType' object is not callable setuptools 82+ removed pkg_resources; PyPI resemble-perth 1.0.1 then sets PerthImplicitWatermarker = None. from_local TypeError used to be mis-labeled as t3_model=v3 Pull latest. Restart (entrypoint pip-installs setuptools<82 when PerTh is not callable) or download-dub --tier clone with the stack up, then restart so perth reimports. Confirm: docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'import perth; assert callable(perth.PerthImplicitWatermarker)'. Do not disable PerTh.
    Dub status faster-whisper not installed Combined pip failed (chatterbox torch pin), named volume predates the wheel bake, or pip landed in the volume venv while Comfy runs /opt/comfy-prebuilt/.venv git pull, stack up (entrypoint heals the interpreter Comfy actually execs). ./scripts/manage.sh download-dub --tier asr. Status should include the ImportError detail (e.g. onnxruntime). Then Queue; Dub status must list speaker/turn counts, not the wheel miss.
    Dub mix is the original clip Old fail-soft returned the source when turns/clone were empty Pull latest. Queue must not write ez_dub_yt from source.wav. Empty mix + status means ASR/clone still missing.
    Dub status missing source.wav / empty turns Ingest never wrote dubs/<slug>/source.wav. I have rights defaults off; Source file defaults (none). Script/render used to hide the ingest reason Read ingest Dub status first (rights refused / empty source / ffmpeg). Pick Source file or Upload media, turn I have rights on, Queue. Files live in ${COMFY_OUTPUT_DIR}/input (container /inputs). After pull, script/render repeat the ingest reason. Local dub
    Dub URL ingest failed yt-dlp missing, or ToS/network ./scripts/utilities/dub-fetch.sh status then install yt-dlp, or Upload media / pick a local file
    Dub voices have a strong English accent in Spanish Chatterbox language-transfer default was cfg_weight=0.5 Pull latest. Clone CFG auto is 0 on EN→ES. Leave it at −1 / 0 unless you want the original accent
    Dub mix is noise / not talking Duration lock used to WSOLA-crush a long Chatterbox take (up to ~40 s) into the original window Pull latest. Fit pitch-preserves up to 1.25×, then spills, then fade-trims. A/B dubs/<slug>/render/turn_NNNN.raw.wav (TTS) vs turn_NNNN.wav (fitted). If raw is speech, it was the old crush. If raw is also noise, check clone pack / speaker refs. Unvoiced clones skip overlay (clone unvoiced in Dub status / qc.json)
    Dub mix starts silent then hums / sounds like creepy music Chatterbox T3 burns 1–3 s of hush tokens; PerTh raises that floor above a −42 dB trim; uncapped max_new_tokens=1000 then walks into a tonal vocoder drone. #183 cropped the tail from t=0, so the operator still heard hush then music Pull latest. Clones are onset-cropped (relative RMS + 80 ms hold) and T3 is capped per line. Raw wav should start on speech. Steady-tone clones skip overlay (clone unvoiced). If raw is still a drone, the speaker ref is dirty or the clone pack is wrong — not duration lock. Do not disable PerTh
    Dub clones sound chipmunked / helium Old duration lock used linear resample (pitch shift) Pull latest. Stretch is ffmpeg atempo (WSOLA fallback) and never faster than 1.25×. If a line is still cut off, shorten text_target (Stage analyze) or accept the fade-trim
    Dub clone does not sound like the speaker Mixed or noisy ref wav under dubs/<slug>/speakers/ Stage analyze, check spkNN.wav is one person / no music bed. Overlap and quiet slices are skipped. Re-Queue Stage render
    YouTube rejects the extra audio Duration mismatch or MLA not enabled Use ez_dub_yt.wav (duration-locked). MLA is rolling out; check Studio → Languages
    Dub mix too quiet / around −30 LUFS Clone sat well below peak; old limiter did not raise Pull latest. Render now raise-to-peak. If still quiet, check dubs/<slug>/qc.json quiet_mix and speaker refs
    “i-translated” English bumper crushes t=0 Spanish Old overlay fitted English disclosure into 3 s on both WAVs Pull latest. Spoken disclosure defaults off. Sidecar only unless you turn it on; bumper never writes onto ez_dub_yt.wav
    text_target is me agradecido / missing clitics Length-matching translate prompt dropped grammar Pull latest. Stage analyze, edit JSON, Rewrite off, Stage render. Default Stage all skips that edit pass
    Demo-script tail modelo de voz / “help you develop” GGUF leaked instruction text into text_target Pull latest. Sanitize drops that tail. Trim the source wav if the leak is in the recording
    Preview MP3 is not 320k / not 48 kHz Comfy SaveAudioMP3 is a 24 kHz preview Expected. MLA master is dubs/<slug>/ez_dub_yt.wav. Optional ez_dub_yt_48k.mp3 in the job dir
    VHS node missing Image/volume predates VideoHelperSuite Pull/rebuild GHCR image and restart
    export-guides exit 2 Compose is up (occupancy) ./scripts/manage.sh stop then dump. DCC guide pack
    blender-stills exit 2 Compose is up (occupancy) ./scripts/manage.sh stop then dump. Blender creator suite
    blender-stills size refuse 1920×1080 or other off-contract size Use 1280×704, 768×1280, 1024×1280, 1024×1024, or 1280×720 (thumb only)
    house-views exit 2 Compose is up (occupancy) ./scripts/manage.sh stop then dump. Dream-house tours
    house-views blender not on PATH Host DCC missing Workbench dump needs host Blender. The clay App still Queues on start / --seed-inputs layout plates. Language-only tour: klein/dream-house. Never add Blender to the Dockerfile
    House clay Missing Inputs / “no file selected” on Clay 01–10 Plates not in ${COMFY_OUTPUT_DIR}/input (LoadImage does not see /outputs) Restart so the entrypoint backstop writes ez_house_clay_01.png … 10.png into /inputs. ./scripts/manage.sh start still prefers layout-accurate plates. While compose is up: ./scripts/manage.sh house-views --slug lab-penthouse --seed-inputs (or --install-inputs if the pack exists), then reload the App
    Guide pack QC refuses 1280×720 LTX VAE grid is 1280×704 (or 768×1280 portrait) Re-export at 704. ez_ltx_spatial is a backstop, not the plan
    Guide pack QC missing canny Dump predates outline pass Re-run export-guides. Canny is Workbench outline, always dumped
    overlay-qc size mismatch Look plate not 1280×704 Re-Queue klein-from-clay at 1280×704. Do not stretch. Clay to finish
    film-animatic missing sources No clay.mp4 and no first.png Dump a guide pack or hold Klein stills under stills/NN.png
    stem-mix / film-accept stem loudness Missing mix or not −14 ± 2 LUFS Pass --bg from the LTX print; stop LTX first. Occupancy audio
    YouTube wants a video, I only have FLAC Audio graphs save FLAC + MP3 on purpose ./scripts/manage.sh audio-still-video --audio FILE --image FILE. Cover from klein-thumbnail (16:9) or klein-podcast-cover (letterboxed). Local music
    Union Control missing LoRA IC-LoRA is opt-in, not download-models ./scripts/manage.sh download-ltx --tier iclora. Distilled-only; refuse 19B
    Occupancy gate refused / occupancy conflict XOR desk: canvas is blender-desk or llm-desk (or the wrong heavy mode) while the graph needs klein / wan / ltx / trellis Park vs stop: dumps use ./scripts/manage.sh occupancy enter blender-desk (Compose stays up, POST /free). Hammer is ./scripts/manage.sh occupancy idle or stop. Then occupancy enter klein\|ltx\|wan\|trellis --yes (does not start Compose). The gate does not spawn Blender. Occupancy desk · Stay in Comfy after a Blender dump
    Sidecar GPU contention (Blender / TRELLIS / ACE next to LTX) Two heavy jobs on GB10 Stop Blender and the 35B sidecar before LTX. occupancy enter ltx --yes after TRELLIS. ACE-Step bed: ./scripts/manage.sh stop (or unload) before LTX A2V freeze. Do not Queue Klein + LTX, TRELLIS + LTX, or ACE + LTX together. Occupancy desk · Studio sidecars
    Splat / Blender park-first Dump or SuperSplat ran while Comfy was a heavy job Before export-guides / blender-stills / house-views / blender: ./scripts/manage.sh occupancy enter blender-desk. SuperSplat and NVENC still want Compose down: ./scripts/manage.sh stop. Never add Blender or SuperSplat to the Dockerfile. Splat sidecar · Blender GB10 sidecar
    studio-ui cache / empty board / wrong port Profile not started; browser holding an old board; looking at App Mode or ${COMFY_PORT} docker compose --profile studio-ui up studio-ui (default start skips it). Board is :8190, not App Mode and not Comfy at ${COMFY_PORT}. Hard-refresh the board tab. Empty films dir is a page, not a crash — compile a film first. 90s shorts
