Open this page when the graph is on screen and the canvas misbehaves: Queue will not start, a preview stays blank, the load aborts, a dub mix comes back wrong, or the board on :8190 is empty. A missing weight, a failed node import, or a stitch that refuses belongs to Models and workflows.

Start here

Three checks settle most canvas rows before you read a table.

  • Hard-refresh the Comfy tab. A large share of canvas failures are the browser holding an old extension bundle while the pack on disk is current.
  • Restart so the entrypoint recopies pack JS. bazelisk run //:manage -- stop then start (type yes), or bazelisk run //:manage -- restart. A Restart inside the UI does not recopy packs.
  • Check the desk. bazelisk run //:manage -- occupancy status names the mode the gate is holding, and Occupancy and sidecars gives the park-vs-stop fix.
