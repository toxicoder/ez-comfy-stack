The occupancy

occupancy

Hardware and safety

One heavy GPU job. Park Comfy for blender-desk or llm-desk; stop those before TRELLIS/LTX.

Open full glossary entry

 rule that decides which of these tools answer (bpy needs the desk) lives on Occupancy desk; the concept is Why one heavy job and the mode-by-job table is Occupancy matrix. This page owns the tools and the tunnels.

No execute_code

In-tree MCP is typed-tool stdio (scripts/lib/blender_mcp.py, research_mcp.py, studio_mcp.py, edit_mcp.py). No execute_code, no telemetry, no arbitrary fetch_url. Official Comfy Cloud MCP / comfy-mcp stay out of the image (manage.sh start is the Comfy launch path). Host only - never in docker/Dockerfile.
