# Download tiers

**What's on this page**

- **One table** — pack, what you get, rough size, download command
- **`--tier` vs `--limit`** — pack id versus Mbps
- **What `all` skips** — Wan VACE / S2V, LTX IC-LoRA, Klein 9B / FLUX.2-dev
- **Banned names** — image `quality`, Nunchaku, DA3-LARGE, DreamX-World, MiniMax H3

**What this enables**

- **Seeing** every pack the stack can pull without opening a page per family
- **Copying** the command that actually downloads that pack
- **Avoiding** a ~47 GB Fun InP pull when you wanted Wan 2.2 5B

`--tier` names a pack id. It is which **pack** that one command pulls, not a quality ladder. `--limit` is Hugging Face bandwidth in Mbps (`auto`, a number, or `off`), not a smaller weight. `download-models` has **no** `--tier`.

Basenames on disk and the container image pin: [Download packs](operate/models-packs.md). Throttle: [Download limit](download-limit.md).

`./scripts/manage.sh download-podcast`, `download-dub`, `download-music`, and `download-llm` already run the pull. 3D, LongCat, DreamX, and SeedVR2 forward to a utility that defaults to a status check, so those commands include the word `run`.

Wan `--tier all` is `5b` + `a14b` + `fun-inp`. It does not include `vace` or `s2v`. LTX `--tier all` is `2.5` + `2.3` + `gemma` and does not include `iclora`. Image `--tier all` is the Apache stills (`fast`, `nvfp4`, `base`, `zimage`) and does not include `9b` or `flux2-dev`. `balanced` is a `2.3` alias, not a 2.5 quality knob. `quality` on LTX is the 2.3 BF16 alias.

## Do not pull

| Name | What happens |
| --- | --- |
| Image `quality` as a `--tier` | Refused. LTX `quality` is a different flag (2.3 BF16) |
| Klein 9B or `flux2-dev` as a lab default | Not the default. Opt-in rows above. FLUX Non-Commercial. Not YouTube-ok |
| Nunchaku 9B | Refused |
| `--tier da3-large` | Refused |
| DreamX-World | Refused |
| MiniMax H3 / `download-h3` | Refused |

Read [Model licenses](licenses.md) before a 30 GB pull. One heavy GPU job at a time — do not Queue Klein next to Wan, LTX, TRELLIS, or `llm-desk`.
