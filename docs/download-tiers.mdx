# Download tiers

**What's on this page**

- **One table** - pack, what you get, rough size, download command
- **`--tier` vs `--limit`** - pack id versus Mbps
- **What `all` skips** - Wan VACE / S2V, LTX IC-LoRA, Klein 9B / FLUX.2-dev / FLUX 3 Image Klein / Qwen-Image 2.1
- **Banned names** - image `quality`, Nunchaku, DA3-LARGE, DreamX-World, MiniMax H3

**What this enables**

- **Seeing** every pack the stack can pull without opening a page per family
- **Copying** the command that actually downloads that pack
- **Avoiding** a ~47 GB Fun InP pull when you wanted Wan 2.2 5B

Open this page when a graph asks for weights you do not have and you want the pack id, the
size, and the one command. `--tier` names a pack id. It is which **pack** that one command
pulls, not a quality ladder. `--limit` is Hugging Face bandwidth in Mbps (`auto`, a number,
or `off`), not a smaller weight. `download-models` has **no** `--tier` - it always pulls the
default still + Wan 5B + LTX-2.5 set.

Weights land in a tier dir under `${MODELS_DIR}` and link into `comfy/`: layout and headroom
live on [Models and cache](models-and-cache.md). Basenames on disk and the container image
pin: [Model packs by family](operate/models-packs.md). Throttle:
[Download limit](download-limit.md). Gated packs need a token **and** a license click:
[Hugging Face tokens](operate/models-tokens.md).

`bazelisk run //:manage -- download-podcast`, `download-dub`, `download-music`, and `download-llm`
already run the pull. 3D, LongCat, DreamX, and SeedVR2 forward to a utility that defaults to
a status check, so those commands include the word `run`.

Wan `--tier all` is `5b` + `a14b` + `fun-inp`. It does not include `vace` or `s2v`. LTX
`--tier all` is `2.5` + `2.3` + `gemma` and does not include `iclora`. Image `--tier all` is
the Apache stills (`fast`, `nvfp4`, `base`, `zimage`) and does not include `9b`,
`flux2-dev`, any `flux3` pack, or any `qwen-image*` pack. `balanced` is a `2.3` alias, not a
2.5 quality knob. `quality` on LTX is the 2.3 BF16 alias.

**FLUX 3 Image Klein is gated.** The six `flux3*` packs all live in
`black-forest-labs/flux-3-image-klein-comfy` (Hugging Face `gated=auto`), so you need
`HF_TOKEN` in `.env` **and** license acceptance on the model card by the **same account as
that token** - a token alone is not acceptance. Each pull is pinned to HF revision
`feef60b0aaf63a4773ace96636ebbcf43b881312`, so a re-run resolves the same commit. License is
**FLUX Kommunity License (v1.0)**, not Apache: monetized output is OK only for qualifying
users under $5M gross annualized revenue. Klein 4B stays the Apache default and the only
still in `download-models`. Read [Model licenses](licenses.md).

**Qwen-Image 2.1 is opt-in and research-licensed.** The four stills and two companion packs
are public and **ungated**: no `HF_TOKEN` in `.env` and no license-accept step on the model
card. `Comfy-Org/Qwen-Image-2.1` (HF revision `aacf31a6d48e707f352ecba714cee0680da3479b`) is
the ComfyUI repack of the official `Qwen/Qwen-Image-2.1` and `Qwen/Qwen-Image-2.1-Turbo`;
`BennyDaBall/Qwen-Image-2.1-NVFP4` (`b0e954a1ba86f00e30f76bac2494f45b0a221948`) and
`BennyDaBall/Qwen-Image-2.1-Turbo-NVFP4` (`82226d8cadaf20a678338f8faf5e5a0cfc3e1dfd`) are
independent NVFP4 conversions of that same Comfy-Org release, not official Qwen or Comfy-Org
releases. The pinned ComfyUI (`COMFYUI_REF=v0.43.0`) loads these natively - Qwen-Image-2.1
support landed upstream in v0.37.0. All six sit under the **Qwen RESEARCH LICENSE AGREEMENT**
(2026-09-20, Hangzhou Tongyi Laboratory), **not Apache**: section 2.b forbids any commercial
use without a separate paid Qwen license, and governing law is China with courts in Hangzhou.
Redistributing the weights means shipping that agreement plus the attribution line "Qwen is
licensed under the Qwen RESEARCH LICENSE AGREEMENT...", and a product built on the outputs
must show **Built with Qwen** in its documentation. Klein 4B stays the recommended still for
anything you publish for money. Read [Model licenses](licenses.md).

## Do not pull

| Name | What happens |
| --- | --- |
| Image `quality` as a `--tier` | Refused. LTX `quality` is a different flag (2.3 BF16) |
| Klein 9B or `flux2-dev` as a lab default | Not the default. Opt-in rows above. FLUX Non-Commercial. Not YouTube-ok |
| Any `flux3` pack as a lab default | Not the default. Opt-in rows above, including the opt-in `labs/opt-in/still-flux3-*` lab graphs. FLUX Kommunity License (v1.0), not Apache. Klein 4B is the default still |
| Any `qwen-image*` pack as a lab default or a monetized pick | Not the default. Opt-in rows above, never in `download-models`. Qwen RESEARCH LICENSE AGREEMENT, not Apache - section 2.b bars commercial use until you hold a separate paid Qwen license. Klein 4B is the default still |
| `Qwen/Qwen-Image-2.1` or `Qwen/Qwen-Image-2.1-Turbo` as a download source | Those are diffusers folders; ComfyUI cannot load one in this stack. The downloader always pulls the Comfy-Org repack `Comfy-Org/Qwen-Image-2.1` |
| Nunchaku 9B | Refused |
| `--tier da3-large` | Refused |
| DreamX-World | Refused |
| MiniMax H3 / `download-h3` | Refused |

Read [Model licenses](licenses.md) before a 30 GB pull. One heavy GPU job at a time - do not
Queue Klein next to Wan, LTX, TRELLIS, or `llm-desk`
([Occupancy desk](occupancy.md)).

## Check the pull

```bash
bazelisk run //:manage -- models-status
```

**Check it worked:** every lab basename is reported present. An opt-in pack is not part of
that check, so confirm its own files landed under `${MODELS_DIR}/<org__repo>_<tier>`:
[Models and cache](models-and-cache.md#layout). A resume that sits at 0 MiB/s:
[Downloads and bandwidth](operate/troubleshooting-downloads.md).
