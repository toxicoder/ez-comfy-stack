# ComfyUI Apps

This page answers one of the four start-creating questions: **what to edit in App
Mode, which lane a graph belongs to, and what to stop before loading the next one**. It covers the App surface itself. Which graph to pick is on
[Workflow catalog](studio-workflows.md), the loop a graph sits in is on
[The still-to-motion-to-AV pipeline](visual-generative-ai.md), and the words you
type are on [Prompting](prompting.md).

**What's on this page**

- **Graph vs App** - what each surface edits, and what the Quality combo owns
- **Reference stills (optional)** - the picker, the three slots, and the mute
- **Occupancy** - the one-heavy-job table and what must be stopped
- **Lane A - Inspire** - the explore desks
- **Lane B - Produce** - the ship plates and clips
- **Lane DCC - clay desk** - the Blender-to-Comfy Apps
- **Handoff chains** - what to load after each App
- **Related** - where to go once you know the surface

**What this enables**

- **Opening a lab graph** from Comfy's **Apps** sidebar, not only Workflows
- **Queueing a lab graph** from creator widgets instead of hunting the canvas
- **Knowing which App to stop** before you load the next one
- **A/B-ing one setup** with the reference stills muted, without clearing what you picked
- **Following Spark Still -> Hero -> Silent 5s -> AV 5s** without renaming files

**Who this is for:** studio users after `stills/still-draft` has been loaded once.

Lab graphs are the host `_lab/<lane>/*.json` files (folder-scoped ids). On `start` they seed into Comfy as `*.app.json` when App Mode is the default view, so they appear under **Apps** as well as **Workflows**. [App Mode](learn/comfyui.md#graph-and-app) is a widget surface on that JSON (ComfyUI frontend **1.41.13+**). It is **not** a second frontend and not [`studio-ui`](reference/studio-ui.md). A small occupancy chip sits at the top of the App widget list (under the menu if you are in graph view) and shows which family is running, a one-line summary of what the App does (`extra.lab_description`), the active Quality overlay, still N of M on multi-plate Apps, and the next handoff. Widget help text wraps so the full description stays readable. It does not cover Run. **Minimize** collapses the chip to an **App - family** pill (click the pill to expand). **Close** hides it until the next run or App load, when it returns as that pill. The choice is stored in this browser. Restart the container after a pull so `custom_nodes/ez_studio_app` is copied.

```mermaid
flowchart LR
  Load["Load _lab graph"] --> App["App Mode widgets"]
  App --> Queue["Queue"]
  Queue --> Out["PNG / MP4"]
  App --> Graph["Graph view to inspect"]
```

## Graph vs App

| Surface | What you edit | When |
| --- | --- | --- |
| **App** | Unique creator widgets. When the graph needs a still, **Start image** (or **First frame** / **Last frame**) is first so Queue cannot hide a missing file. Then **Quality** (Lab / Draft / High), **Sample prompt** (30 lab recipes + **Custom**), **Prompt**, **Format / platform** (on Apps that own a canvas), **Output size** (Match input uses a loaded still's aspect; Force format keeps the Format pick), **Duration** (LTX 5/8/10/12 s, default 8 s; Wan stays 5 s), **Style** (`none` = off), **Rewrite prompt**, then **Seed**, then Width / Height (and Batch on Klein stills). Format sets pixels and Rewrite prompt framing; Custom uses the size widgets (Klein div16, Wan div16, LTX div32 - pick **LTX - 16:9 YouTube (1280x704)**, never type 720). Filename / LoadImage / LoadAudio widgets upload a file or choose one already on the output disk. **Start image** only when that LoadImage is wired (I2V, talking-head, character tweak, clay, text-swap). Optional references stay empty by default. The App surfaces **Example / reference (optional)** (one LoadImage-style picker) and the **Use reference stills** mute; the node card adds the two extra pickers, thumbnails, and the drop zone. Blank is the default and Queues as text-to-image. **motion/av/first-last-8s** exposes **First frame** and **Last frame**. **motion/av/audio-to-video-8s** exposes **Audio file**. **motion/av/clip-chain** keeps Start image first, then Quality, Sample prompt (Beat 1), four **Beat N prompt** boxes, Format, Output size (Match input), Duration (default 8 s), Describe image, shared Rewrite / Audio notes / Logline, Seed, then Width / Height (Custom only). Occupancy stays on the chip, not as an App combo. Style is hidden on I2V (the start frame owns look). **stills/still-studio** also adds **Look recipe**, Image model, and Steps / CFG - prefix follows Format. **stills/image-studio** adds **Mode category**, **Creator mode** (100 presets), Look recipe, Image model, Steps / CFG, and **Example / reference (optional)** - prefix follows Creator mode. **stills/still-daily** keeps Image model + steps/CFG. Music adds duration + vocal/instrumental; podcast adds bed length + Kokoro stock voices; **audio/podcast/learn-episode** adds **Sources**, **Format**, and **Duration** (ACE bed stays 30 s and loops); dub adds source file + upload, optional URL, rights, and target language. Duplicate widgets get distinct labels (Klein prompt / Wan prompt, Beat 1 prompt, Bed tags). | Daily Queue |
| **Graph** | Groups, bypass (Ctrl+B), VHS preview, UNET/CLIP/VAE, hidden shot cards, unwired placeholders (Fun InP end frame, VACE shot B), voice-clone refs | Debug, film one-click, unused plates |

**Quality** is a workflow-global combo (`EZQuality`) near the top of `linearData` (first on graphs with no required still; second when a LoadImage picker leads). Picking a tier writes Steps / CFG / Image model (and CLIP / VAE) on **every** sampler and loader instance in the open App (Vue-safe widget writes) and does not live-link other open tabs. Newly opened Apps default to the last named Quality you picked in this browser.

The combo is read from the widgets, not write-only: it is recomputed on graph load, on graph change, on any widget edit, and at Queue, and reports the named tier whose parameters the widgets actually hold - **lab** when they match the values the graph was authored with, **custom** otherwise. Only the parameters that family's tiers own are compared, so editing a parameter no tier touches (CFG on a Wan graph) keeps the level. **custom** is not absorbing: put the owned widgets back on a tier's values and that tier is re-derived. The caption under the combo names the transformer and the sampler settings Queue will send. Prompt / tags / lyrics edits Queue at every Quality; typing the box selects Sample prompt **custom** so the textarea is what encodes.

A tier that cannot be written is a **failed apply**, not a silent skip. If the tier's model file is not in that loader's combo list, or the widget is not built yet, the write is refused, the combo goes to **custom**, and the caption names what diverged. Nothing queues under the tier name with the old weights still in the widgets.

Tiers are named profiles that swap weights, not a step ladder. `custom_nodes/ez_quality/presets.py` is the only definition; `custom_nodes/ez_quality/js/ez_quality_presets.js` is generated from it, so regenerate with `bazelisk run //tests:build_quality_js` after editing presets.py (hand-editing the generated file is a defect).

| Family | What the tiers own | Real rows |
| --- | --- | --- |
| Klein stills | steps, CFG, UNET, CLIP, VAE, CLIP type | draft 4 steps (Klein 4B nvfp4, CFG 1.0), standard 8 (Klein 4B fp8), `high` and **Free Commercial Use (\<$10M)** are the same profile - Klein 4B base, 24 steps, CFG 3.5. `ultra` is only 4 steps because it swaps to Klein 9B distilled; `max` is 20 steps on Klein 9B base |
| FLUX 3 Image stills (`stills/still-flux3-*`) | steps, CFG, UNET, CLIP, VAE, CLIP type | only `flux3-fast` (16 steps, CFG 1.0) and `flux3-quality` / `flux3-nvfp4` (50 steps, CFG 3.5) apply. The Klein ladder is a no-op there |
| Wan / LTX / film | steps only - never CFG, never weights | draft 12, standard 20, `high` 28, `ultra` 28 (= `high`), `max` 32. Free Commercial Use is 28 on LTX / film and writes nothing on Wan |
| Audio (ACE-Step) | steps only | draft 4, standard 8, `high` 16, `ultra` 16 (= `high`), `max` 24. Free Commercial Use writes nothing |
| TRELLIS | steps only | draft 8, standard 12, `high` 20, `ultra` 20 (= `high`), `max` 28. Free Commercial Use writes nothing |

Quality does not touch the Width / Height or Duration widgets, and Quality is not `--tier quality` (that flag is a download pack id - [Download tiers](download-tiers.md)). The one size effect is **Free Commercial Use (\<$10M)** on Klein stills: a generic 16:9 / 9:16 **Format** row retargets to **16:9 LTX feeder (1280x704)** / **9:16 LTX feeder (768x1280)**; named platform jobs, **Custom**, and rows already on a feeder stay put. ultra/max may select opt-in Non-Commercial weights (gated, not YouTube-ok). Inspire desks (no UNET) still show the combo as a no-op.

`EZQuality` nodes that are muted or bypassed (LiteGraph `mode` other than 0) are ignored by the overlay and wear no caption. The 90s film acts (`workflows/_lab/films/<slug>/act-02.json` .. `act-05.json`) mute the copied-in Klein lane, the combo included, on purpose - acts 2+ take the previous act's frame as their image source, so set the tier on **act-01**.

The CLI submits the same table: `./scripts/utilities/print-shot.sh <film> <id> --quality TIER` and `./scripts/utilities/album-render.sh run --album ARTIST/SLUG --quality TIER` (or `EZ_QUALITY=TIER`) overlay the graph before each POST; with neither, the tier the graph records is used.

Official persist is `extra.linearData` (`inputs` / `outputs`). Each input is `[nodeId, widgetName, config?]` with an **integer** node id. ComfyUI frontend **1.49.6+** (this stack pins **1.57.4** with v0.43.0) upgrades that to a live `graphId:nodeId:name` WidgetId at load. Do **not** persist `"11:prompt"` two-part ids - the frontend treats a colon as a subgraph locator and drops the widget, leaving App view with Run and occupancy but no Prompt. The lab contract is `extra.lab_app_mode` (`lane`, `occupancy`, `handoff`, `frontend_min`). Do not require `extra.linearMode` - upstream does not write it.

Comfy's **Apps** sidebar lists files whose name ends in `.app.json`. On `start`, the entrypoint seeds every App Mode graph (`default_view: app`) as `_lab/<lane>/*.app.json`. The same stem still appears under **Workflows** in that folder. 90s film graphs stay `default_view: graph` (too many widgets) and keep the `.json` suffix - App Mode is still **enabled**, but they stay Workflows-only. Folders do not add `workflows/apps/`.

Filenames: [Workflow catalog](studio-workflows.md). Playbook: [The still-to-motion-to-AV pipeline](visual-generative-ai.md). Restart the container after a pull so the `.app.json` copy runs.

Save your own Apps under **`_user/`**. Duplicate a lab graph (App Forge, Save As `_user/`, or a new file under live `_lab/`) and it stays in `_user/`. A Save that overwrites live `_lab/<lane>/*.app.json` is rescued into `_user/_rescued/` on the next `start` - re-open a rescued file, because `_lab/` is the shipped catalog. If `_user/_rescued/` is already full of catalog clones from older starts, delete that folder (keep the rest of `_user/`). Folder rules and the sidebar tree: [Workflow catalog](studio-workflows.md#where-the-graphs-live).

## Reference stills (optional)

**Example / reference (optional)** is the App label for the canvas node **Optional reference stills** (`EZOptionalImage`). Every Klein graph in the catalog ships it empty. Leave it blank and Queue: the graph runs text-to-image exactly as before. That is the default path, not a fallback.

Give the model something to look at when you need it:

1. Pick a still in **Example / reference (optional)**. To attach more than one, use **+ Add reference** on the node card to reveal the other two pickers (`filename_2`, `filename_3`). Each one is a real LoadImage-style picker: drag a file onto the card's drop zone, upload, choose a file already on disk, or pick a name from `input/`. A wired IMAGE batch also lands on the node.
2. Read the card status line. `Reference stills: 2 of 3` means two stills attach, `No reference still - Queue as is` means Queue runs text-to-image, and `Reference stills muted` means the mute has them parked. A wired batch reads `plus a wired batch`. Each filled slot shows a thumbnail, so you can see what is going in.
3. Queue. Up to three picked stills plus one wired batch reach Klein / Flux.2 as real reference latents.
4. To compare with and without the stills, turn the **Use reference stills** mute off (the node widget reads **Use references** / **References off**) and Queue again. The stills stop reaching the model - the node reports `references off` - and your picks stay put, so turning it back on restores them. Picking a new still also turns the mute back on for you. Do not clear the picker to A/B.

**Klein canvas (optional ref)** (`EZKleinRefCanvas`) attaches at most **max_refs** frames (1-4, default 3). Set it to 1 to make one still dominate, or when a wired batch is sending more frames than you meant.

Nothing about the node name, its outputs, or the App input label changed, so graphs you saved keep loading. A graph saved against the older node keeps its single picker and gets the toggle plus the two extra pickers at their defaults (references on, extra slots empty).

Stills that will not apply: [Troubleshooting](troubleshooting.md#reference-stills-optional-refs). Node table: [Custom nodes](reference/custom-nodes.md#ez_image).

## Occupancy

One GB10 job. Cover art != film != podcast. Every App Note includes a one-line occupancy stanza.

| Occupancy | Allowed | Must be stopped |
| --- | --- | --- |
| `none` / `llm` | Prompt Forge, Research Chat, Beat Sheet | nothing GPU |
| `klein` | still Apps + Platform Pack | Wan, LTX, podcast, music |
| `wan` | silent 5 s / GIF / bumper | LTX, podcast, music |
| `ltx` | any AV 8 s App | Wan, podcast, music, other LTX |
| `film` | 90 s one-click | everything else on that Spark |
| `audio` | podcast / dub / rap | Klein / Wan / LTX session |

Prompt Enhance GGUF stays CPU-only (`n_gpu_layers=0`). Sidecar occupancy (Comfy XOR Blender) is unchanged: [Host sidecars overview](studio-sidecars.md). `export-guides` / `blender-stills` / `house-views` die if compose is up.
