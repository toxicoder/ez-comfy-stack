# DCC guide pack

**What's on this page**

- **Operator loop (Path B)** - park, dump, Klein the look, print depth-guided, mix stems
- **Pack contract** - `guides/<film-id>/<shot>/`, the files, and the fail-closed QC
- **Still packs** - one clay plate -> hero / packshot / IG / shorts (`guides/<slug>/stills/<plate>/`)
- **Guide pack or house tour** - how this pack differs from the Dream-house clay tour
- **Lab graphs** - the `dcc/*` printers, their occupancy desk, and the IC-LoRA envelope
- **Paths** - A engine-final, B hybrid clay -> AI finish, D laptop-DCC / Spark-Comfy
- **Host gates inside the loop** - script desk, animatic, overlay QC, and stem mix on host ffmpeg

**What this enables**

- **A 5.00s LTX print that keeps the camera you blocked** in the 3D app
- **Creator stills (hero, packshot, IG, shorts)** from one clay plate
- **Fail-closed packs** - 1280x704 or 768x1280, 120 frames @ 24 fps - before Comfy sees them
- **Laptop DCC / Spark Comfy as the default** on one GB10

**Question this page answers:** how do I get a 3D blockout into Comfy so the print keeps my camera and timing? This is the contract page: what a pack must contain, what each graph eats, and which verb parks the GPU. The concept and order of operations live in [Clay blockout to finished clip](learn/clay-to-finish.md); the dump itself runs on the host in [Blender GB10 sidecar](blender-gb10-sidecar.md).

This extends `ez_film`. It does **not** replace the 5.00s printer ([Short films](shorts.md)) or the sidecar occupancy rule. Blender stays on the host - never in `docker/Dockerfile` or Compose. After a dump, stay on `:8188` with first-party `ez_dcc` loaders: [Stay in Comfy after a Blender dump](learn/comfy-first-blender.md).

<Callout type="error" title="One heavy GPU job">
  Pack writing is a host GPU job. `export-guides` **dies** (exit 2) if Compose is up and not parked. Park with `occupancy enter blender-desk`, or `occupancy idle`. `restart: "no"` is unchanged. [Occupancy desk](occupancy.md). Full wording of the one-heavy-job rule and the park / stop verbs: [Host sidecars overview](studio-sidecars.md#occupancy-rule).
</Callout>

## Operator loop (Path B)

```bash
./scripts/manage.sh occupancy enter blender-desk
./scripts/manage.sh export-guides --engine blender --film go-see --shot 12 --blend /path/to/shot.blend --print ltx-iclora-depth
./scripts/manage.sh occupancy enter klein --yes
# Queue workflows/_lab/dcc/clay-hero.json on first.png
./scripts/manage.sh overlay-qc --film go-see --shot 12 --look /path/to/ez_clay_hero.png
# After download-ltx --tier iclora: Templates -> LTX-2.5 Union Control, depth from depth.mp4
# Stop LTX. Stem mix (occupancy audio):
./scripts/manage.sh stem-mix --film go-see --shot 12 --bg /path/to/print.mp4
```

Cheap pacing gate (host ffmpeg; compose may stay up):

```bash
./scripts/manage.sh film-animatic --film go-see
```

Script desk writes `films/<slug>/shots.yaml` (does not clobber lab YAML):

```bash
./scripts/manage.sh shot-sheet run --film go-see
```

Default on one GB10 is **Path D**: block and MCP on the laptop, rsync `guides/` to the Spark, Spark only runs Comfy.

```bash
rsync -a guides/go-see/12/ spark-0:/mnt/comfy-output/guides/go-see/12/
./scripts/manage.sh start
```

## Pack contract

`${COMFY_OUTPUT_DIR}/guides/<slug>/<shot_id>/`

`<slug>` here is the film id you pass to `--film` (`go-see`), not the output prefix (`gosee`). `blender-guide`, `film-animatic`, and `overlay-qc` use that directory. `films/<prefix>/` and `ez_<prefix>_*.mp4` keep the prefix. An existing `guides/<prefix>/` pack is read only when `guides/<film-id>/` is absent.

| File | Rule |
| --- | --- |
| `shot.yaml` | `ez.guide.shot.v1` - 120 frames, 24 fps, **1280x704** or **768x1280** |
| `first.png` / `last.png` | Exact LTX VAE grid. Never 1280x720 |
| `rgb/` + `clay.mp4` | Workbench / unshaded clay. Not Cycles beauty |
| `depth/` + `depth.mp4` | Mist 0-1, near=white / far=black. Raw metric Z is a QC fail |
| `canny/` + `canny.mp4` | Workbench outline / Freestyle line-art (always dumped) |
| `normal/` | Optional EEVEE Normal (`--include-normal`); omitted when EEVEE is missing |
| `camera.json` | Per-frame extrinsics (`pos` / `rot` / `fov`) |

QC is fail-closed: wrong size, wrong frame count, or compose-up -> non-zero, pack not marked ok.

Clay is Workbench. **Beauty MP4 is Path A only** (engine-final ingest in a later PR).

## Still packs (not 120 frames)

`${COMFY_OUTPUT_DIR}/guides/<slug>/stills/<plate>/` - `ez.guide.still.v1`. Allowed sizes: 1280x704, 768x1280, 1024x1280, 1024x1024, 1280x720 (thumb, Klein only).

```bash
./scripts/manage.sh occupancy enter blender-desk
./scripts/manage.sh blender-stills --film go-see --plate mug --blend /path/to/prop.blend --size 1024x1024
./scripts/manage.sh occupancy enter klein --yes
# Queue klein-from-clay-plates or klein-from-canny
```

`--install-inputs` copies `first.png` into `${COMFY_OUTPUT_DIR}/input` (compose may stay up). Playbook: [Blender creator suite](learn/blender-creator.md).

## Guide pack or house tour

Two clay dumps, two contracts. Do not mix them.

| | DCC guide pack (this page) | Dream-house clay tour |
| --- | --- | --- |
| Verb | `export-guides`, `blender-stills` | `house-views` |
| On disk | `guides/<film-id>/<shot>/` | `assets/sets/<slug>/` |
| Shape | 120 frames @ 24 fps, **1280x704** or **768x1280** | ten stills, **1024x1280** (Instagram 4:5) |
| Schema | `ez.guide.shot.v1` / `ez.guide.still.v1` | `ez.house.views.v1` |
| Then Queue | `dcc/clay-hero`, `dcc/depth-control-8s` | **stills/dream-house-clay** |

`house-views` also writes a greybox GLB beside the ten clay stills. Do not dump Instagram 4:5 into `guides/` or reuse `ez.guide.shot.v1` - that QC is 1280x704 / 120 frames and will refuse. Park the same way (`occupancy enter blender-desk`):

```bash
./scripts/manage.sh house-views --slug lab-penthouse
```

Playbook, layout seed, and the language-only door: [Dream-house tours](learn/dream-house.md).

## Lab graphs

| Graph | Occupancy | Notes |
| --- | --- | --- |
| **inspire/beat-sheet** | none | Script desk. Logline, audio policy, 18 cards. `shot-sheet` writes YAML. |
| **dcc/clay-hero** | klein | Edit `first.png`, Enhance **on**, seed **42**, 1280x704. Overlay-qc after Queue. |
| **dcc/clay-plates** | klein | One clay still -> hero / packshot / IG / shorts. Ctrl+B unused groups. |
| **dcc/canny-hero** | klein | Edit `canny.png`, 1280x704, prefix `ez_canny_hero`. |
| **dcc/depth-control-8s** | ltx | Envelope. Templates -> LTX-2.5 Union Control. Depth default. Distilled-only. Refuse 19B. MagCache off. |
| **dcc/canny-control-8s** | ltx | Same envelope; wire `canny.mp4`. |
| **dcc/depth-control-shorts** | ltx | Same envelope at **768x1280**. Dump with `--width 768 --height 1280`. |
| **dcc/first-last-from-guide** | wan | Fun InP `first.png` + `last.png`. Opt-in `download-wan --tier fun-inp`. MagCache off. |
| **dcc/guide-still** | klein | In-canvas `EZDCCLoadGuideStill` + occupancy gate. Prefix `ez_guide_hero`. Stay on `:8188`. |
| **dcc/depth-from-loader** | ltx | Envelope from loaders + `depth.mp4` path. MagCache off. Distilled-only. Prefix `ez_iclora_guide`. |
| **dcc/still-to-mesh** | trellis | Still pack `plate=mug` -> native TRELLIS.2 INT8. Output `assets/objects/_lab-mug/`. |
| **audio/stem-mix** | audio | Stem mix desk. Host `stem-mix.sh`. ACE-Step group stays off. |

Print modes `wan-vace`, `wan-denk-cn`, and `dcc-final` stay valid on `shot.yaml` but are **not** lab printers in this suite (VACE stays 17-frame join; Fun Control / Path A beauty are later).

```bash
./scripts/manage.sh download-ltx --tier iclora   # not download-models
```

Official 2.5 Union Control distilled widgets `ltx-2.3-22b-ic-lora-union-control-ref0.5.safetensors` onto the **distilled** transformer. Distilled-only. **Refuse 19B Union.** MagCache off.

## Paths

| Path | Meaning |
| --- | --- |
| **A** Engine-final | DCC beauty MP4 -> jobstore later (`dcc-final`). No AI video. |
| **B** Hybrid clay -> AI finish | DCC owns layout/camera/timing. AI owns materials/faces/light. **This PR.** |
| **D** Laptop-DCC / Spark-Comfy | Default ergonomics on one GB10. |

Godot is a first-class blocking engine in a later PR, not a second Blender. OpenToonz / Krita are plate emitters into the same pack, not v1 engines.

## Safety

- Do not weaken `restart: "no"`, heavy confirm, `mem_limit: 90g`, `min_host_free_gib: 28`, or download-limit clear-on-exit.
- Never queue a DCC dump and a print in one session.
- Unload Klein before LTX. IC-LoRA is not part of `download-models`.
- `overlay-qc` / `film-animatic` / `stem-mix` do not start Docker and do not weaken occupancy XOR for dumps.
- Park Comfy before a live Blender MCP socket (`occupancy enter blender-desk`). Do not run Cycles CUDA next to a loaded denoise.
- LTX-2.5 is the Community License audio model and IC-LoRA is opt-in; Wan is Apache. Weights rows: [Model licenses](licenses.md).
