## What the studio is

ez-comfy-stack is a **sample US-safe local studio**: ComfyUI in Docker on **one** NVIDIA
DGX Spark, with Apache Klein 4B stills, Apache Wan 2.2 silent motion, and LTX-2.5 joint AV.

It is **not** nvidia-dgx-spark-lab (no K3s, no dashboard, no multi-node NCCL). How the
pieces fit: [Architecture](architecture.md). When to graduate:
[This stack or nvidia-dgx-spark-lab](../start/when-to-use-vs-spark-lab.md).

## Two jobs, one machine

```mermaid
flowchart TB
  subgraph Host["DGX Spark host"]
    Op["Operator: manage.sh"]
    Compose["Docker Compose - restart: no"]
    Weights["MODELS_DIR weights"]
    Out["COMFY_OUTPUT_DIR media"]
  end
  subgraph Studio["Studio in the browser"]
    UI["ComfyUI :8188"]
    Graph["_lab graph"]
    Q["Queue"]
  end
  Op --> Compose --> UI
  Weights -.-> UI
  UI --> Graph --> Q --> Out
```

You can be both people. First-time path is still operator-shaped (clone, doctor, download,
start), then you become a studio user for the first still.

## What you make

Text -> **still** (Klein) -> **silent ~5 s** (Wan) -> **AV ~5 s** (LTX). Iterate in minutes.
A 90 s YouTube short is **18 x 5 s** prints stitched, not one 90 s denoise.

```mermaid
flowchart LR
  T["Prompt"] --> K["Klein T2I PNG"]
  K --> W["Wan I2V silent MP4"]
  K --> L["LTX I2V AV MP4"]
```

Learn the models: [Klein, Wan, and LTX](pipeline.md). Learn the math-lite version of latents
and steps: [Image and video generation](generation.md). Learn why SSH-safe defaults exist:
[Hardware, memory, and safety](hardware.md).
