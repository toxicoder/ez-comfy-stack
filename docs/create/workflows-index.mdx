# Workflow details

**What's on this page**

- **How to read** a generated workflow page (purpose, graph, node table, parameter reference)
- **Where pages live** — one page per unique `_lab` graph, one page per album
- **The node encyclopedia** that inlines at the bottom of every details page

**What this enables**

- **Opening a filename** and seeing every node, widget, and legal combo without raw JSON
- **Changing a sampler or latent size** with a documented generation effect

**Who this is for:** studio users who already Queued `stills/still-draft`. Scan tables stay on the [Workflow catalog](../studio-workflows.md).

After `download-models` + `start`, load graphs from Comfy **Workflows** / **Apps**. These pages document the **seeded JSON**, not a live Queue.

```bash
export SPARK_HOST="${SPARK_HOST:-127.0.0.1}"
export SPARK_USER="${SPARK_USER:-$USER}"
export MODELS_DIR="${MODELS_DIR:-/mnt/models}"
export COMFY_OUTPUT_DIR="${COMFY_OUTPUT_DIR:-/mnt/comfy-output}"
export COMFY_PORT="${COMFY_PORT:-8188}"
export DOWNLOAD_LIMIT="${DOWNLOAD_LIMIT:-auto}"
```

<Callout type="warning" title="Generated pages">
  Per-graph pages under `docs/generated/workflows/` are built from `workflows/_lab/**/*.json` plus `docs/workflow_nodes.py`. Do not hand-edit them. Re-run `python3 docs/generate_workflow_docs.py` (or `make docs`). Combo lists are ComfyUI **v0.37.0** and lab `INPUT_TYPES` — not SD1.5 folklore.
</Callout>

## How a details page is laid out

1. **Purpose** — occupancy, models, the on-canvas Note
2. **How to Queue** — Apps vs Workflows, do not edit raw `_lab` JSON
3. **Graph** — mermaid of nodes (small graphs) or **groups** (dream-house, 90s films)
4. **Nodes on this graph** — every node id, title, type, group
5. **Node parameter reference** (bottom) — every unique type on that graph:
   - sockets
   - each widget in lab JSON order
   - **this graph's value**
   - what the parameter does to the still / clip / audio
   - **other legal choices** (samplers, CLIP types, styles, ACE language, …)

90s one-click films (239 nodes) document the identity printer + one LTX shot template once, then list all 18 shot instances in the node table. Album tracks share one ACE-Step topology: unique lyrics/tags/seed live in per-track H2 sections; the parameter reference is at the bottom of the album page.

## Lab knobs that are easy to get wrong

| Widget | Lab default | What goes wrong |
| --- | --- | --- |
| **Quality** | **lab** | Not `--tier quality`. Draft/High only change family sampler (and Klein 4B UNET). Distilled Klein High without Klein base keeps CFG 1.0 |
| Klein **cfg** | **1.0** | Raising CFG is not a quality knob on distilled Klein — change the Positive prompt or use still-hero |
| LTX **height** | **704** | 720 and 1080 are not ÷32; `ez_ltx_spatial` snaps them |
| LTX **length** | **121** (`1+8n`) | Do not Queue a 90 s latent. 90s films stitch 18 × 5.00 s |
| Wan I2V **prompt** | Motion + one camera | The start still owns look. Do not prompt audio (silent) |
| VHS **save_output** | **true** | false means no file on `${COMFY_OUTPUT_DIR}` |
| Prompt **Enhance** | on for lazy printers; **off** for authored recipes / 90s / albums | On will rewrite exclusive verses and film shot cards |
| Occupancy | one heavy family | Do not co-resident Klein / Wan / LTX / audio |

Prompt shapes: [Prompting](../prompting.md). Generation theory: [Image and video generation](../learn/generation.md).
