# Motion graphs

Pick a motion graph. This catalog covers time-based jobs on one loaded still or
one plain text prompt: a silent ~5 s Wan 2.2 clip, an ~8 s LTX-2.5 audio-video
take, a loopable GIF or bumper, and the creator motion plates. The still you
feed them is on [Stills graphs](workflows-stills.md) and the film plate + print-pass
apps are on [Film graphs](workflows-film.md).

**What's on this page**

- **Motion (Wan 2.2 5B)** - silent I2V / T2V, FLF, VACE, A14B, TRELLIS, GIF loop
- **AV hero (LTX-2.5)** - I2V / T2V and the div32 size rule
- **Showcase (LTX-2.5)** - dialogue, native multishot, product hero, first-last-frame, A2V freeze
- **Creator toolkit** - motion and AV plates (orbit, bumper, B-roll, hook)
- **Duplicate clip-chain beats** - extending the four-beat chain to 5-24
- **Related** - what to load after the clip lands

**What this enables**

- **Queuing a silent ~5 s clip** or an AV ~8 s hero from a seeded filename
- **Keeping LTX widgets** on the native VAE grid so prints do not snap-and-crop
- **Reading one table per family** so you can pick a row in seconds
- **Chaining four AV beats** with last-frame continuity instead of copy-pasting nodes

**Who this is for:** studio users after a Klein still. Index: [Workflow catalog](../studio-workflows.md). Node-by-node widgets: [Workflow details](workflows-index.md).

**How to read these tables.** The **Workflow** column is the lab id you load from
`_lab/`, and it links to the generated node page for that graph. **What it does**
names the job, the default pixels, the frame count, the MagCache state, the
output prefix, and the occupancy the graph claims. Park the previous family
before you Queue the next one - rules every lab graph shares are on
[Workflow catalog](../studio-workflows.md#shared-lab-graph-rules).

<Callout type="warning" title="LTX width/height must be divisible by 32">
  Broadcast 720p (**1280x720**) and 1080p (**1920x1080**) are **not** native LTX VAE sizes (720/16=45, then the next `/2` patch fails). Lab landscape graphs use **1280x704**. Klein **I2V feeders** (`klein-still-hero`, 90s film identity) are **1280x704**. Thumbnails/end-cards may stay 1280x720. On LTX Apps pick **Format / platform -> LTX - 16:9 YouTube (1280x704)** instead of typing 720. Typing 720 or 1080 on LTX widgets is **auto-snapped** (704 / 1056) by `ez_ltx_spatial` - prefer 704 so you skip the extra crop. Portrait shorts I2V is **768x1280**. See [Troubleshooting](../troubleshooting.md).
</Callout>

## Duplicate clip-chain beats (5-24)

Shipped **[video/av/clip-chain](../generated/workflows/video/av/clip-chain.md)** is four beats. Duplicate **Beat** groups on the canvas for longer chains. App Mode will not pick up Beat 5+ prompts. 4 x 8 s sequential prints are tens of minutes on GB10. Occupancy **ltx** XOR.

1. Duplicate the last Beat group.
2. Set `VHS_VideoCombine.filename_prefix` to `ez_clip_b05_ltx_video` (then b06...).
3. Set last-frame SaveImage prefix to `ez_clip_b05_last`.
4. Wire previous `EZClipLastFrame.last_frame` -> new `LTXVImgToVideo.image`.
5. Wire new `VHS_VideoCombine.Filenames` -> the next free `EZClipConcat.clip_0N` (`clip_05` for the fifth beat).
6. Keep the shared UNET / VAE / CLIP / Format / Seed / Rewrite / Audio notes wires (do not duplicate loaders).
7. Save under `_user/` if you want a personal App; shipped `_lab` stays 4 beats.

Past 24 stems: host `bazelisk run //scripts:run-utility -- concat-shots --files a.mp4,b.mp4 --cap-seconds <sum> --yes` (the default `--files` cap is 90 s).
