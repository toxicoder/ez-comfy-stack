# The still-to-motion-to-AV pipeline

This page answers one of the four start-creating questions: **what the whole
end-to-end loop is, and how to iterate on it**. You end up with a still, a silent
~5 s clip, and an ~8 s audio-video take off one seed, in minutes rather than a
90 s denoise. Which graph to load is on [Workflow catalog](studio-workflows.md),
what the widgets do is on [ComfyUI Apps](studio-apps.md), and how to word each
prompt is on [Prompting](prompting.md).

**What's on this page**

- **Architecture (one screen)** - the profile, tiers, and memory limits this page assumes
- **Combined pipeline (Klein -> Wan -> LTX)** - the one-stack handoff and the license-clean path
- **Iteration loop (YouTube 16:9)** - the ordered Queue list you actually follow
- **Watch the video (Wan / LTX)** - where the MP4 lands and how long it runs
- **Commands** - the day-to-day manage.sh verbs
- **Safety** - what this page never weakens
- **Related** - what to read next in the Studio tab

**What this enables**

- **Running still, silent motion, and AV tools** in **one** Docker Compose stack
- **Iterating in minutes** on ~5 s clips instead of a 90 s denoise
- **Chaining one seed** from draft still to hero still to clip without renaming files
- **Knowing what to stop** before the next family Queues

**Who this is for:** studio users after `stills/still-draft` has queued once.

## Combined pipeline (Klein -> Wan -> LTX)

Text -> still -> **silent 5 s** -> **AV 8 s** in one ComfyUI stack.

```mermaid
flowchart LR
  Prompt["Text prompt"] --> Klein["Klein 4B T2I<br/>fast - distilled FP8"]
  Klein --> Image["Still PNG"]
  Image --> Wan["Wan 2.2 I2V<br/>5B - 5 s silent"]
  Wan --> Silent["MP4 silent"]
  Image --> LTX["LTX-2.5 I2V<br/>distilled - 8 s AV"]
  LTX --> Mp4["MP4 + world audio<br/>VHS_VideoCombine"]
```

**Handoff (start in App Mode):** load **stills/still-draft** -> enter App Mode -> Queue Spark Still -> open **stills/still-hero** (same seed) -> set **motion/silent/still-to-video-5s** LoadImage to `ez_still_draft_*.png` or `ez_still_hero_*.png` -> Queue ~5 s silent -> optional **motion/av/still-to-video-8s** for native audio. Showcase: **motion/av/dialogue-8s** (quoted speech), **motion/av/multishot-8s** (named cuts), **motion/av/product-hero** (packshot), **motion/av/first-last-8s** (two stills), **motion/av/audio-to-video-8s** (freeze a wav). Platform jobs (channel art, 4:5 feed, Canvas, BRB): [Creator pack](create/workflows-creator.md) - same occupancy XOR, e.g. **creator/stills/youtube-shorts-thumb** -> **creator/silent/zoom-punch**. Stop Wan before LTX (occupancy). I2V graphs also Queue on Comfy's default **example.png**. Apps catalog: [ComfyUI Apps](studio-apps.md).

LTX-2.5 is a **joint audio/video** transformer. Seeded LTX graphs load the **audio VAE**, create matching empty audio latents, concat them with video latents before `KSampler`, then decode audio with **`LTXVAudioVAEDecode`** into **`VHS_VideoCombine`** so the MP4 includes world audio. Text conditioning is a single **CLIPLoader** (`gemma4-12b-with-proj-ltx-2.5-comfy-int8-convrot`, type **`ltxv`**).

### Free Commercial Use (\<$10M)

License-clean AV path for a company under the LTX Community License revenue cap. Quality combo **Free Commercial Use (\<$10M)** on Klein and LTX Apps. Do not put Klein 9B or FLUX.2-dev on this path (those are FLUX Non-Commercial). On Klein it is the same profile as `high` - Klein 4B base, 24 steps, CFG 3.5 - so the caption reads `flux-2-klein-base-4b-fp8, 24 steps, CFG 3.5`; on LTX it sets 28 steps and touches neither CFG nor weights. If `flux-2-klein-base-4b-fp8.safetensors` is not in that loader's list the combo falls to **custom** and names what diverged instead of queueing the old weights (`./scripts/manage.sh download-models`, then **Check models**).

1. **Still** - Klein **4B** at clip size. Landscape **1280x704**. Portrait **768x1280**. Pick a seed on **Draft** (4-step, Klein 4B nvfp4), then Queue this quality at the **same** pixels - it swaps the weights and steps only, never Width / Height. Generic 16:9 / 9:16 **Format** rows retarget to **16:9 LTX feeder (1280x704)** / **9:16 LTX feeder (768x1280)**; named platform jobs, **Custom**, and rows already on a feeder stay put.
2. **Optional polish** - SeedVR2 on that PNG (`download-restore --tier seedvr2-3b`). Add detail at ~1.3-1.5x. Do not jump to 4K. Stop Comfy first.
3. **Motion** - same PNG into **motion/av/still-to-video-8s** (LTX-2.5 I2V). Prompt only the motion and sound. Let LTX's own 2x upscaler / DFR Templates handle resolution.
4. **Unload Klein before LTX.** Occupancy chip; one GB10 job. 90s films already pass the identity still through **Unload models**.

Wan silent 5 s stays the Apache rehearsal path (no $10M cap, no native audio). On Wan / audio / TRELLIS graphs Free Commercial Use writes nothing, and every tier there sets steps only - never CFG, never weights - with `ultra` repeating `high`.

<Callout type="info" title="Pipeline tips">
  1. Download the default pack first (`download-models` = image fast + wan 5b + ltx 2.5)
  2. Prefer keeping both model sets loaded between T2I and I2V
  3. Do not GPU-offload a 30B+ llama.cpp next to LTX; Prompt Enhance is CPU-only (~2.5 GiB GGUF)
  4. Video graphs emit **MP4** via **VideoHelperSuite** (`VHS_VideoCombine`, 24 fps) plus optional PNG frames
  5. Prompting: Klein wants Qwen-style prose (subject -> light -> camera); Wan wants motion + one camera move (no audio); LTX wants a present-tense paragraph with sound interleaved. See [Prompting](prompting.md). Every seeded lab canvas has an operator **Note** at the top-left; the graph then reads left-to-right below it.
</Callout>

## Iteration loop (YouTube 16:9)

Do **not** edit raw JSON. Change widgets on the canvas.

1. Load **stills/still-draft** -> set Positive prompt + seed (fixed) -> Queue (minutes, 4-step).
2. Pick a frame under `${COMFY_OUTPUT_DIR}` (`ez_still_draft_*.png`).
3. Load **motion/silent/still-to-video-5s** -> set LoadImage to that PNG (or leave `example.png` to smoke-test) -> edit **Motion / prompt** only -> Queue ~5 s silent.
4. Optional audio: **motion/av/still-to-video-8s**, same first frame, same seed note, Queue ~5 s AV at **1280x704**.
5. Short six-shot demo: Queue **motion/silent/still-to-shot** six times (`ez_shot_01` ... `06`) then:

    ```bash
    ./scripts/utilities/concat-shots.sh --yes
    # default dir is ${COMFY_OUTPUT_DIR}; writes ez_concat_shots.mp4
    ```

6. **90s films** (go-see first-person parkour / still-here / switchyard): load one **film-*-90s** graph -> Queue **once** -> the MP4 is already at `${COMFY_OUTPUT_DIR}/ez_<slug>_90s.mp4` (faststart). A **90s film ready** overlay plays and downloads it; `ez_<slug>_90s.html` is a local player. See [Short films](shorts.md).
7. Daily still / GIF / IG pack: **stills/image-studio** (100 creator modes + Format / platform + optional reference; **Iterate** for text-to-image then edit, **This run** for the values Queue will send) or **stills/still-studio** (Format / platform + Style + Rewrite prompt) or **stills/still-daily** -> optional **motion/loops/gif-loop** (LoadImage = the still prefix you just saved, leave ping-pong on) or **stills/dream-house** for a 10-photo virtual tour of one place (type any place; each still a different room or view - tower, foyer, lounge, kitchen, dining, bedroom, bath, terrace, drone, study). Same walkthrough with 3D persistence: **stills/dream-house-clay** (`start` seeds clay plates; optional `house-views` dump) ([Dream-house tours](learn/dream-house.md)). Character loop: **stills/character-draft** -> **stills/character-tweak** (`ez_character_*.png`). Lettering swap: **stills/text-swap** (output matches the source still). Environment: **stills/background-swap** (new place, including ground) or **stills/background-edit** (restyle in place).
8. Creator toolkit: vertical Shorts still->I2V, thumbnail, packshot, before/after, style lock, bumper, B-roll, storyboard 6-up - [catalog](studio-workflows.md).

Do not Queue a 90s denoise. Default graphs iterate in minutes; one-click films are 18 x 5s prints.

## Watch the video (Wan / LTX)

<Callout type="info" title="Primary output is MP4">
  Seeded **wan-*** and **ltx-*** graphs install **ComfyUI-VideoHelperSuite** and wire **`VHS_VideoCombine`** after video `VAEDecode` (`save_output: true`). LTX graphs also run **`LTXVAudioVAEDecode`** into the VHS **audio** input so world audio is muxed into the MP4. After **Queue**, open **Save video (MP4) - open node for preview** for an **inline preview**. PNG **Save frames (secondary)** is optional. Files are on the **host** at `${COMFY_OUTPUT_DIR}` (container `/outputs`). `cleanup` does **not** delete this folder.
</Callout>

```bash
ls "${COMFY_OUTPUT_DIR}"/ez_still_draft_*.png
ls "${COMFY_OUTPUT_DIR}"/ez_ltx_*_video_*.mp4
```

| Graph | Frames | FPS | ~ duration |
| --- | --- | --- | --- |
| `wan-i2v-5s` / `wan-t2v-5s` | 121 | 24 | ~5.04 s (Wan 5B official max) |
| `ltx-*-8s` standalone Apps | 193 | 24 | **~8.04 s** (duration-head allows 5/8/10/12 s) |
| `wan-i2v-shot` | 120 | 24 | **5.00 s** |
| `ltx-i2v-shot` / 90s film printers | 121 | 24 | **~5.04 s** (LTX `1+8n`; concat 5.00 +/- 0.05) |
| 90s film (18 LTX prints + concat) | - | 24 | **90.00 s** cap |

<Callout type="warning" title="Do not Queue a 30 s / 60 s / 90 s latent">
  Long latents melt Spark. Standalone LTX Apps default to **193 frames (~8 s)**. Film graphs still use **121-frame** LTX printers (`1+8n`, 18 shots + stitch, cap 90 s). **120 is illegal** and decodes as 113 frames / 4.71 s. Keep headroom preflight green. A one-click film Queue is **long wall-clock**, not a 90s denoise.
</Callout>
If **`VHS_VideoCombine` is missing**, pull/rebuild the image and restart so install refresh can clone VideoHelperSuite - see [Troubleshooting - studio canvas](operate/troubleshooting-canvas.md) and [Troubleshooting - models and workflows](operate/troubleshooting-models-workflows.md).

??? abstract "Lab workflow internals"

    - Name pattern: host files `workflows/_lab/<lane>/*.json` (unique id is `extra.lab_rel`; entrypoint rsyncs into `user/default/workflows/_lab/`)
    - Every graph has a ComfyUI **Note** node + `extra.lab_note` with the same operator guidance
    - Klein CLIP loader type is **`flux2`** with `qwen_3_4b` + `EmptyFlux2LatentImage` (simplified `KSampler`)
    - LTX-2.5 graphs use **CLIPLoader** (`gemma4-12b-with-proj-ltx-2.5-comfy-int8-convrot`, type **`ltxv`**), save **MP4** via **`VHS_VideoCombine`** (h264, 24 fps)
    - LTX is **joint AV**: empty audio latents concat with video before `KSampler`, then **`LTXVAudioVAEDecode` -> `VHS_VideoCombine.audio`**
    - Lab Klein graphs use **core** loaders only (not ComfyUI-nunchaku)

??? abstract "Optional LTX-2.3 fallback"

    If LTX-2.5 access or INT8-convrot fails: `./scripts/utilities/download-ltx.sh run --tier 2.3` pulls Kijai distilled FP8 + Gemma 3 DualCLIP. **Seeded lab graphs still expect LTX-2.5 filenames** - do not treat 2.3 as the default playbook.
