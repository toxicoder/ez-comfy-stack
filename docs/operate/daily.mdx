# Daily loop

**What's on this page**

- **The loop** - doctor, start, queue one job, stop
- **Where each step is proved** - the check after every command
- **Port forward** - reach the canvas from a laptop
- **Stop before reboot** - the one rule that keeps SSH recoverable

**What this enables**

- **Opening** the studio without re-reading Getting Started
- **Leaving** the host in a state SSH can recover
- **Jumping** to occupancy or troubleshooting when the loop breaks

**Who this is for:** operators after the first successful still. First install:
[Getting Started](../getting-started.md).

Run everything from the repo root on the Spark. Do not weaken `restart: "no"`, the **yes**
confirm on `start`, the headroom preflight, or download-limit **clear-on-exit**.

---

## End of the loop

| Goal | What you end with |
| --- | --- |
| **UI** | ComfyUI at `http://${SPARK_HOST}:${COMFY_PORT}` (or the laptop port forward) |
| **Job** | One occupant (klein / wan / ltx / desk) |
| **Stop** | Container down before any reboot |

---

## Run the loop

1. `./scripts/manage.sh doctor`

   **Check it worked:** it prints `Doctor OK`. Missing weights are a warning, not a fail.
   Fail: [Host and Docker](troubleshooting-host-docker.md).

2. `./scripts/manage.sh start` - type **yes**

   **Check it worked:** `./scripts/manage.sh status` shows the project up. A headroom refuse
   is a hard fail by design.

3. Open `http://${SPARK_HOST}:${COMFY_PORT}`, load a `_lab` App, and Queue **one**
   occupancy chip at a time.

   **Check it worked:** the media lands under `${COMFY_OUTPUT_DIR}`.

4. Optional: park for Blender or the writing desk instead of a full stop -
   [Occupancy desk](../occupancy.md).

   **Check it worked:** `./scripts/manage.sh occupancy status` names the mode you entered.

5. `./scripts/manage.sh stop` before any reboot -
   [Reboot safety](../reboot-safety.md).

   **Check it worked:** `./scripts/manage.sh status` shows Comfy is not running.

---

## Open the canvas from a laptop

```bash
ssh -L "${COMFY_PORT}:127.0.0.1:${COMFY_PORT}" "${SPARK_USER}@${SPARK_HOST}"
```

Then open `http://127.0.0.1:${COMFY_PORT}`.

**Check it worked:** the canvas loads on the laptop. If the port is taken, `status` still
shows Comfy up on the Spark: [Start and runtime](troubleshooting-start-runtime.md).

---

## When the loop stalls

Weights already on disk? Skip `download-models`. **Missing Models** on the canvas is a
cache problem, not a graph bug - [Models and workflows](troubleshooting-models-workflows.md).
One heavy GPU job at a time; a second denoise is how SSH dies.
