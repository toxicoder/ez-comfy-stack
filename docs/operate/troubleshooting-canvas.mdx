# Troubleshooting — studio canvas

**What's on this page**

- **Studio-user symptoms** on the Comfy canvas (Missing Models, LTX 720, Nodes 2.0, dub, DCC dumps)
- **Occupancy XOR** — park vs stop, sidecar contention, splat/Blender park-first
- **studio-ui board** on :8190 vs App Mode on `${COMFY_PORT}`

**What this enables**

- **Unblocking** Queue, preview, and dump failures from the canvas
- **Keeping** one heavy GPU job on GB10 (park for dumps; `stop` for SuperSplat/NVENC)

<Callout type="error" title="One heavy GPU job">
  GB10 is XOR. Park with `./scripts/manage.sh occupancy enter blender-desk` for Workbench dumps; `./scripts/manage.sh stop` for SuperSplat/NVENC. Do not Queue LTX next to Blender, TRELLIS, ACE-Step, or the 35B sidecar. [Occupancy desk](../occupancy.md).
</Callout>

## Studio user (canvas)

| Symptom | Likely cause | Action |
| --- | --- | --- |
| **Missing Models** on a seeded lab graph | Weights not on `MODELS_DIR` / broken `comfy/` symlink | `./scripts/manage.sh download-models` then restart. [Models and cache](../models-and-cache.md) |
| Nodes look tiny / groups overlap after load | LiteGraph sizes under Nodes 2.0, or `workflowRendererVersion` stamped `"Vue"` | Confirm Settings **Nodes 2.0** and **Auto-scale layout** are on. Lab JSON must be `Vue-corrected`, not `"Vue"` (that shrinks geometry 1.2×). Seeded graphs are spaced for Vue widget height — re-open the catalog copy after pull. Restart so `start` reseeds settings when those keys are absent. [ComfyUI basics](../learn/comfyui.md) |
| Preview widgets blank / Upload media missing under Nodes 2.0 | Old `ez_*` JS (`inputEl` / `node_widget`) or a third-party LiteGraph-only pack | Pull latest and restart so `ez_prompt_enhance` / `ez_research` / `ez_dub` JS copies. Toggle Nodes 2.0 off only if a **user** pack is LiteGraph-only. [Custom nodes](../reference/custom-nodes.md) |
| Invalid input: Sample prompt value (Cliff villa, …) is not available | Comfy validates `sample` against the node combo, not the App-filtered catalog | Pull latest and restart so `ez_prompt_enhance` recopies. Re-open the seeded graph. [Models and workflows](troubleshooting-models-workflows.md) |
| History empty after `start` / image pull | PromptServer history is in-memory; files are on the output bind | Open the **Outputs** sidebar (grid or list, thumbnails). Select multiple files for bulk delete / copy to input, or **Use as start image** (copies into `${COMFY_OUTPUT_DIR}/input`). [Custom nodes](../reference/custom-nodes.md) |
| Start images vanished after `cleanup` | LoadImage files lived on the named volume | Put start frames in `${COMFY_OUTPUT_DIR}/input` (container `/inputs`). `cleanup` does not delete `COMFY_OUTPUT_DIR` |
| LTX `einops` / divide by 45 | Width/height not ÷32 (720 or 1080) | Pick **Format / platform → LTX · 16:9 YouTube (1280×704)**. `ez_ltx_spatial` auto-snaps; prefer 704 over typing 720 |
| No MP4 preview, only PNGs | Old graph without VHS, or looking at SaveImage | Re-open seeded `wan-*` / `ltx-*`; open **Save video (MP4)** node |
| LTX MP4 has no sound | Missing audio VAE decode → VHS (or A2V freeze not on LoadAudio) | Re-open current **ltx/***. **motion/av/audio-to-video-8s** muxes **LoadAudio**, not `LTXVAudioVAEDecode` — pick `ez_a2v_bed.wav` in `/inputs` |
| LTX AddGuide `combined AV latent is not supported` | First/last guides were wired after `LTXVConcatAVLatent` | Use **motion/av/first-last-8s**. Guides pin the **video** latent, then audio concat |
| FLF last frame ignored | Second LoadImage unwired or bypassed | App widgets **First frame** and **Last frame** must both be set. Same aspect, 1280×704 |
| Prompt box is read-only | A **Sample prompt** recipe is selected | Pick **Custom** in the Sample prompt dropdown. The last recipe stays in the box so you can edit it. |
| Wan prompt has two camera verbs | Subject also named a dolly/pan, or Enhance invented a second move | Cinema Rack already emits one `wan_token`. Leave the move out of Subject. Family `wan_t2v` / `wan_i2v`. [Cinema Rack](../create/cinema-rack.md) |
| Style stripped bleach-bypass / noir grade | Style dropdown is not `none` | Cinema Rack owns camera/light/time. Keep Enhance **style** at `none` on **inspire/cinema-rack** |
| ACE vocal sings the instrumental bed | Lyrics leaked outside `[inst]` / `[drop]` | Audio Rack instrumental / podcast-bed emits empty-body markers. Keep production cues inside the brackets. [Audio Rack](../create/audio-rack.md) |
| Tags BPM disagrees with the encoder | Tempo axis set 88 but `TextEncodeAceStepAudio1.5` still 140 | Match encoder BPM to the rack **notes** line (`BPM: 88`) |
| Living-artist name in the take | Brief named a living MC | Audio Rack catalogs ban living artists. Keep Brief original. Human-edit lyrics before release |
| Editing pick did nothing on a still | Flavor is `klein` | Editing is omitted on stills (`still_mode: omit`). Use `ltx_t2v` or `wan_t2v` |
| Enhance did nothing | GGUF / llama.cpp missing, or local LLM timed out | Read **Enhance status**. `GGUF missing` → `download-models` then restart. `llama.cpp unavailable` → Llama did not import (pip “already satisfied” is not enough). Queue self-heals, then force-reinstalls the GitHub manylinux wheel. If status still has a `docker exec … pip install --force-reinstall` line, run it (no image rebuild). Confirm: `docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'from llama_cpp import Llama'`. Default timeout is **180s** (`EZ_LLM_TIMEOUT_S`) on **8** CPU threads (`EZ_LLM_N_THREADS`) |
| Dub Queue says **rights refused** | **I have rights** is off (default) | Turn it on only when you own the recording or have speaker consent. [Local dub](../dub.md) |
| Dub **Source file** is `(none)` / empty source | Nothing selected in the dropdown | **Upload media**, or pick a file already in `${COMFY_OUTPUT_DIR}/input`. Do not type a host path |
| Dub file not in the Source dropdown | File is under `/outputs`, or the App was open before `dub-fetch` | Put media in `${COMFY_OUTPUT_DIR}/input` (container `/inputs`). Reload the App. [Local dub](../dub.md) |
| Dub **Upload media** missing | Pack JS not copied, or the browser is holding an old frontend | Restart the container so entrypoint copies `ez_dub/js/`. Hard-refresh the Comfy tab |
| Dub empty mix / no transcript | faster-whisper or Chatterbox missing, ASR/clone snapshot incomplete, or translation cannot run | **Dub status** names the miss. `download-dub --tier asr` (needs `model.bin`, `config.json`, **and** `tokenizer.json`) then `--tier clone` (`ve.pt`, `s3gen.pt`, T3 V3, tokenizer JSON, `Cangjie5_TC.json`, `conds.pt`) with the stack **up**. Restart also heals wheels (entrypoint pip, including Chatterbox V3 `t3_model`). Do **not** `pip install faster-whisper chatterbox-tts` as one command — chatterbox pins torch 2.6 and blocks ASR. Do **not** `pip install chatterbox-tts` from PyPI (0.1.7 has no `t3_model=v3`). |
| Dub status / log `qwen3tts extra not installed — download-podcast --tier qwen3tts` | Old path named a **weights** command for a **wheel** miss (`from qwen_tts import Qwen3TTSModel`). Status used to spam once per turn | Pull latest. New status names `pip install --no-deps qwen-tts` (extras `einops` `soundfile` first). Never unconstrained `pip install qwen-tts` (pins `transformers==4.57.3`). Weights/tokenizer: `./scripts/manage.sh download-podcast --tier qwen3tts` (complete snapshot, not `model.safetensors` only). Queue fail-fasts: one Dub status, empty mix, no chatterbox fallback |
| First chatterbox Queue HEADs `Cangjie5_TC.json` / writes `/root/.pkuseg/` | `from_local` still called Hub; pkuseg downloaded ontonotes into the container home | Pull latest. `download-dub --tier clone` keeps `Cangjie5_TC.json` and seeds `${MODELS_DIR}/pkuseg`. Compose sets `PKUSEG_HOME=/models/pkuseg`; entrypoint symlinks `/root/.pkuseg`. ~280 s for 7 turns on GB10 is inference, not a leftover download |
| Dub status `llama.cpp unavailable` / English `text_target` | Llama did not import (wheel metadata can be present). Queue used to copy source into `text_target` and clone English as the target | Pull latest. Queue self-heals `llama-cpp-python` (CPU extra-index, then GitHub manylinux `--force-reinstall --no-deps`). If **Dub status** still names a `docker exec … pip install --force-reinstall` command, run that line. Confirm: `docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'from llama_cpp import Llama'`. Queue **stops before ASR** when Rewrite translation is on and source ≠ target (empty mix + that status). |
| Dub status `chatterbox-tts missing t3_model=v3` | Volume still has PyPI 0.1.7 (`from_local` has no `t3_model`) | Pull latest. Restart or `download-dub --tier clone` with the stack **up** (force-reinstalls the GitHub zip `--no-deps`). Confirm: `from inspect import signature; from chatterbox.mtl_tts import ChatterboxMultilingualTTS; 't3_model' in signature(ChatterboxMultilingualTTS.from_local).parameters`. |
| Dub status `resemble-perth watermarker missing` / `chatterbox failed: 'NoneType' object is not callable` | setuptools 82+ removed `pkg_resources`; PyPI `resemble-perth` 1.0.1 then sets `PerthImplicitWatermarker = None`. `from_local` TypeError used to be mis-labeled as `t3_model=v3` | Pull latest. Restart (entrypoint pip-installs `setuptools<82` when PerTh is not callable) or `download-dub --tier clone` with the stack **up**, then restart so perth reimports. Confirm: `docker exec ez-comfy-studio /comfy-state/ComfyUI/.venv/bin/python -c 'import perth; assert callable(perth.PerthImplicitWatermarker)'`. Do **not** disable PerTh. |
| Dub TTS logs `LoRACompatibleLinear is deprecated` / `sdp_kernel() is deprecated` | Chatterbox Matcha still constructs diffusers' deprecated Linear; generate uses torch's old SDPA context manager | Pull latest and restart (`pythonpath/` is bind-mounted). Lab sitecustomize maps `sdp_kernel` → `sdpa_kernel` and aliases `LoRACompatibleLinear` to `nn.Linear`. Do **not** `pip install peft` (that flips diffusers' LoRA backend). `loaded PerthNet (Implicit)` is expected — PerTh stays on. |
| Dub status `faster-whisper not installed` | Combined pip failed (chatterbox torch pin), named volume predates the wheel bake, or pip landed in the volume venv while Comfy runs `/opt/comfy-prebuilt/.venv` | `git pull`, stack **up** (entrypoint heals the interpreter Comfy actually execs). `./scripts/manage.sh download-dub --tier asr`. Status should include the ImportError detail (e.g. `onnxruntime`). Then Queue; **Dub status** must list speaker/turn counts, not the wheel miss. |
| Dub mix is the original clip | Old fail-soft returned the source when turns/clone were empty | Pull latest. Queue must not write `ez_dub_yt` from `source.wav`. Empty mix + status means ASR/clone still missing. |
| Dub status `missing source.wav` / empty `turns` | Ingest never wrote `dubs/<slug>/source.wav`. **I have rights** defaults off; Source file defaults `(none)`. Script/render used to hide the ingest reason | Read ingest Dub status first (`rights refused` / `empty source` / ffmpeg). Pick **Source file** or **Upload media**, turn **I have rights** on, Queue. Files live in `${COMFY_OUTPUT_DIR}/input` (container `/inputs`). After pull, script/render repeat the ingest reason. [Local dub](../dub.md) |
| Dub URL ingest failed | yt-dlp missing, or ToS/network | `./scripts/utilities/dub-fetch.sh status` then install yt-dlp, or **Upload media** / pick a local file |
| Dub voices have a strong English accent in Spanish | Chatterbox language-transfer default was `cfg_weight=0.5` | Pull latest. **Clone CFG** auto is **0.3** on EN→ES (0 disabled text-following). Leave it at −1 unless you *want* more of the original accent (raise toward 0.5) |
| Dub mix is noise / not talking | Duration lock used to WSOLA-crush a long Chatterbox take (up to ~40 s) into the original window | Pull latest. Fit pitch-preserves **up to 1.25×**, then spills, then fade-trims. A/B `dubs/<slug>/render/turn_NNNN.raw.wav` (TTS) vs `turn_NNNN.wav` (fitted). If raw is speech, it was the old crush. If raw is also noise, check clone pack / speaker refs. Unvoiced clones skip overlay (`clone unvoiced` in Dub status / `qc.json`) |
| Dub mix starts silent then hums / sounds like creepy music | Chatterbox T3 burns 1–3 s of hush tokens; PerTh raises that floor above a −42 dB trim; uncapped `max_new_tokens=1000` then walks into a tonal vocoder drone. #183 cropped the *tail* from t=0, so the operator still heard hush then music | Pull latest. Clones are **onset-cropped** (relative RMS + 80 ms hold) and T3 is capped per line (floor 200 tokens). Raw wav should start on speech. Steady-tone clones skip overlay (`clone unvoiced`). If raw is still a drone, the speaker ref is dirty or the clone pack is wrong — not duration lock. Do not disable PerTh |
| YT preview `ez_dub_yt_*.mp3` is ~source length but has no Spanish (tone, hush, or ducked English) | Clone failed `is_speech_like` (PerTh/Chatterbox leftover) or ingest `job_slug` became `True` from the Upload media button (5-wide widgets: slug leaked into URL, job dir `dubs/True/`). Fixture: `ez_dub_yt_00058.mp3` | Pull latest. Check **Dub status** (`clone unvoiced — empty mix` is the honest miss — Comfy preview is 1-sample empty, not a 64 s tone). Inspect `dubs/<slug>/render/turn_*.raw.wav`. Job dir must be `dubs/episode/`, not `dubs/True/`. `download-dub --tier asr` then `--tier clone` with compose up. Never treat a duration-matched drone as success. |
| Dub mix / raw wav is a sliding moan (“whale”) with no words | Cross-lang Clone CFG auto was `0.0` (T3 CFG off → looping speech tokens → HiFT F0-glide). The old speech-like gate only rejected *steady* 90 Hz leftover, so the moan was mixed | Pull latest. Auto CFG is **0.3** (retry **0.5**). F0-glide moans fail `is_speech_like` (speech-band + tonal frames) and skip overlay. If every take is still a moan: Dub status `clone unvoiced — empty mix`, raise **Clone CFG** toward 0.5, or pick **Clone engine** `qwen3tts` after `download-podcast --tier qwen3tts`. Do not disable PerTh |
| Dub clones sound chipmunked / helium | Old duration lock used linear resample (pitch shift) | Pull latest. Stretch is ffmpeg `atempo` (WSOLA fallback) and never faster than 1.25×. If a line is still cut off, shorten `text_target` (Stage **analyze**) or accept the fade-trim |
| Dub clone does not sound like the speaker | Mixed or noisy ref wav under `dubs/<slug>/speakers/` | Stage **analyze**, check `spkNN.wav` is one person / no music bed. Overlap and quiet slices are skipped. Re-Queue Stage **render** |
| YouTube rejects the extra audio | Duration mismatch or MLA not enabled | Use `ez_dub_yt.wav` (duration-locked). MLA is rolling out; check Studio → Languages |
| Dub mix too quiet / around −30 LUFS | Clone sat well below peak; old limiter did not raise | Pull latest. Render now raise-to-peak. If still quiet, check `dubs/<slug>/qc.json` `quiet_mix` and speaker refs |
| “i-translated” English bumper crushes t=0 Spanish | Old overlay fitted English disclosure into 3 s on both WAVs | Pull latest. Spoken disclosure defaults **off**. Sidecar only unless you turn it on; bumper never writes onto `ez_dub_yt.wav` |
| Dub mix / FLAC starts with 1–3 s of silence while Spoken disclosure is off | Duration-locked mix kept the source leading gap (and clone hush) on `ez_dub_mix` | Pull latest. Off: mix/FLAC starts on speech. MLA file is still duration-locked `dubs/<slug>/ez_dub_yt.wav` |
| `text_target` is `me agradecido` / missing clitics | Length-matching translate prompt dropped grammar | Pull latest. Stage **analyze**, edit JSON, Rewrite **off**, Stage **render**. Default Stage **all** skips that edit pass |
| Demo-script tail `modelo de voz` / “help you develop” | GGUF leaked instruction text into `text_target` | Pull latest. Sanitize drops that tail. Trim the source wav if the leak is in the recording |
