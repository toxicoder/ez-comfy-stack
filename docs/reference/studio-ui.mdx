# studio-ui

**What's on this page**

- **Optional profile** `studio-ui` — default `start` does **not** launch it
- **No GPU** — 512m, `restart: "no"`, port `${STUDIO_UI_PORT:-8190}`
- **Routes** — `/`, `/watch/<slug>`, `/media`, `/thumb`
- **Allowlisted 90s masters** — `gosee` / `stillhere` / `switchyard`
- **Not App Mode** — Lane A / Lane B live on [ComfyUI Apps](../studio-apps.md)

**What this enables**

- **A lights board** for clay / look / overlay / print / audio after `compile-film` / `print-shot`
- **Watch / download** of an allowlisted 90s MP4 without opening Comfy
- **Leaving** the widget catalog on App Mode (this page does not duplicate it)

```bash
export SPARK_HOST="${SPARK_HOST:-127.0.0.1}"
export SPARK_USER="${SPARK_USER:-$USER}"
export MODELS_DIR="${MODELS_DIR:-/mnt/models}"
export COMFY_OUTPUT_DIR="${COMFY_OUTPUT_DIR:-/mnt/comfy-output}"
export COMFY_PORT="${COMFY_PORT:-8188}"
export DOWNLOAD_LIMIT="${DOWNLOAD_LIMIT:-auto}"
```

Source: `studio-ui/server.py`. Compose: `docker/docker-compose.yml` service `studio-ui`.

<Callout type="warning" title="Default start skips this profile">
  `./scripts/manage.sh start` (type **yes**) starts **comfyui** only. studio-ui is `profiles: ["studio-ui"]`. It does not weaken `restart: "no"`, headroom, or occupancy XOR. **No GPU.**
</Callout>

## Not App Mode

| | **ComfyUI App Mode** | **studio-ui** |
| --- | --- | --- |
| **What** | Widget surface on the same `_lab` JSON | Separate Alpine Python HTTP board |
| **Where** | Comfy frontend on `${COMFY_PORT}` | Compose profile, host `${STUDIO_UI_PORT:-8190}` |
| **GPU** | Occupancy of the graph you Queue | None |
| **Catalog** | [ComfyUI Apps](../studio-apps.md) Lane A Inspire / Lane B Produce | This page (lights + allowlisted MP4) |

Do not treat studio-ui as a second Comfy. The occupancy chip in App Mode comes from `custom_nodes/ez_studio_app` ([Custom nodes](custom-nodes.md)). Minimize it to a corner pill or close it when it covers the canvas; the choice is stored in this browser.

## Start the board

From the repo root (same project name as `manage.sh`):

```bash
docker compose -f docker/docker-compose.yml --project-name ez-comfy --profile studio-ui up studio-ui
# http://${SPARK_HOST}:8190
# or http://127.0.0.1:${STUDIO_UI_PORT:-8190} after you map the port
```

Compose maps `${STUDIO_UI_PORT:-8190}:8190`. The process inside the container listens on **8190** (`ThreadingHTTPServer(("0.0.0.0", 8190), …)`). Image `python:3.12-alpine`. Bind-mount `${COMFY_OUTPUT_DIR}:/films:ro` plus `studio-ui/` read-only. `mem_limit: 512m`. `restart: "no"`.

Empty films dir is a **page**, not a crash: “No films yet. Run `./scripts/utilities/compile-film.sh go-see` then `print-shot`.”

## Routes

| Path | What |
| --- | --- |
| **`/`** | Jobstore lights: clay / look / overlay / print / audio per shot from `films/<slug>/state.json`. Clay, look, and overlay read `guides/<film-id>/<shot>/` (`go-see`). `guides/<prefix>/` (`gosee`) is used only when that shot directory is absent |
| **`/watch/<slug>`** | HTML5 player for an **allowlisted** 90s master |
| **`/media/<slug>`** | MP4 bytes. `?dl=1` sets `Content-Disposition` attachment |
| **`/thumb?slug=&shot=&kind=`** | PNG thumb. `kind` is `clay` (`first.png`) or `overlay` (`overlay.png`). `slug` is a film id (`go-see`) or output prefix (`gosee`); shot digits. `..` and slashes 404 |

Unknown / missing allowlist → **404**.

### Allowlisted 90s masters

Resolved under the Comfy output root (`/films` bind = `${COMFY_OUTPUT_DIR}`):

| Slug | File |
| --- | --- |
| `gosee` | `ez_gosee_90s.mp4` |
| `stillhere` | `ez_stillhere_90s.mp4` |
| `switchyard` | `ez_switchyard_90s.mp4` |

Path is `realpath`-jailed to that root. Stitch still writes those names via `EZFilmConcat` / `concat-shots.sh`. 90s playbook: [90s shorts](../shorts.md).
