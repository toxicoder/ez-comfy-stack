# Custom nodes

**What's on this page**

- **Every pack** under `custom_nodes/` (`ez_common` ... `ez_quality` ... `ez_outputs` ... `ez_studio_blocks`)
- **Mapped nodes** from `NODE_CLASS_MAPPINGS` / `INPUT_TYPES` / `RETURN_TYPES`
- **Empty mappings** - helpers, LTX spatial patch, App occupancy chip, Outputs sidebar, subgraphs
- **Frontend JS** under Nodes 2.0 (preview `widget.value`, no LiteGraph `inputEl` / `node_widget`)
- **QC / rights** notes that ship on the node `DESCRIPTION` (nothing invented)

**What this enables**

- **Looking up** a canvas class without opening `nodes.py`
- **Seeing** occupancy widgets vs graph labels (`llm` is not a CLI mode)
- **Keeping** App Mode widgets on [ComfyUI Apps](../studio-apps.md) (this page is the pack catalog). Per-graph widgets: [Workflow details](../create/workflows-index.md) - [Workflow node parameters](workflow-nodes.md)

Entrypoint copies these packs into `$COMFY_HOME/custom_nodes/` on `start`. Operator-installed packs live on `${COMFY_OUTPUT_DIR}/custom-nodes-user` (`_user/`) and are not overwritten.

```bash
export SPARK_HOST="${SPARK_HOST:-127.0.0.1}"
export SPARK_USER="${SPARK_USER:-$USER}"
export MODELS_DIR="${MODELS_DIR:-/mnt/models}"
export COMFY_OUTPUT_DIR="${COMFY_OUTPUT_DIR:-/mnt/comfy-output}"
export COMFY_PORT="${COMFY_PORT:-8188}"
export DOWNLOAD_LIMIT="${DOWNLOAD_LIMIT:-auto}"
```

<Callout type="warning" title="Occupancy and licenses">
  One heavy GPU job on GB10. In-canvas **Occupancy gate** reads `${COMFY_OUTPUT_DIR}/.occupancy.json` only - it does not start Compose. LTX Community License disclosure nodes are not legal advice. Dub Queue refuses unless **I have rights** is on.
</Callout>

## ez_outputs (Outputs sidebar)

**No canvas nodes.** `NODE_CLASS_MAPPINGS` is empty. `WEB_DIRECTORY = ./js`.

`ez_outputs.js` registers a Comfy **Outputs** sidebar tab (**Browse saved generations**). It lists media on `${COMFY_OUTPUT_DIR}` (container `/outputs`), skips `comfy-user` / `custom-nodes-user` / `input` / `temp`, and is a thumbnail browser - not only a path list:

- **Grid** (default, reflowing `auto-fill`) or **List**, with an adjustable thumbnail size (80-280px, persisted)
- Multi-select (checkbox, Shift-click range, Ctrl/Cmd-click, Select all) and bulk **Delete** / **Copy to input** / **Download** / **Copy paths**
- Stills use Comfy `/view?preview=webp;80` thumbs; video plays on hover; double-click opens a lightbox
- **Use as start image** copies into `/inputs` and sets `LoadImage.image` (then `EZOptionalImage.filename`); audio sets `LoadAudio.audio`

Comfy History is in-memory and empty after `start`; these files persist. Sort, view, and thumb size live in `localStorage`. Routes: `GET /ez_outputs/list` (`truncated` when the 500-file cap clips), `POST /ez_outputs/delete`, `POST /ez_outputs/to-input`. Bodies accept a single `rel` or a `rels` list. Path traversal and non-media files are refused.
